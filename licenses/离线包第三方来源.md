# 离线包的第三方来源

| 组件 | 来源和许可 | 随包文件 |
| --- | --- | --- |
| Python 3.13.17 x64 嵌入版 | [Python 官方发行](https://www.python.org/downloads/release/python-31317/)，PSF 许可 | `runtime/python-portable/LICENSE.txt`；依赖的许可证在 `Lib/site-packages` 对应目录内 |
| 网页 | React、Mantine、Markdown 等生产依赖 | `licenses/frontend/` 存放安装包自带的许可证和声明；仅带已构建网页 |
| Python 3.9 中文文档 | [PSF 文档许可](https://docs.python.org/3.9/license.html)，代码示例可采用 0BSD | `licenses/python-3.9-license.html`，原文与接收记录在 `kb/_reference/python39/` 和 `docs/data/r1-reference-import.json` |
| BGE 语义编码器 | [BAAI 原模型](https://huggingface.co/BAAI/bge-small-zh-v1.5) 标注 MIT；[Xenova 的 ONNX 转换](https://huggingface.co/Xenova/bge-small-zh-v1.5) | 项目已有 int8 ONNX 和同目录分词文件；`licenses/BAAI-bge-small-zh-v1.5-README.md` 保留原模型说明 |
| llama.cpp b11669（含解释模型的包） | [ggml authors，MIT](https://github.com/ggml-org/llama.cpp/blob/b11669/LICENSE)；原生运行库另含 LLVM OpenMP | `licenses/llama.cpp-b11669-LICENSE`、运行目录内 `LICENSE-LLVM-OpenMP` |
| Qwen3.5 9B / 4B（按所选模型） | [9B](https://huggingface.co/Qwen/Qwen3.5-9B/blob/main/LICENSE) / [4B](https://huggingface.co/Qwen/Qwen3.5-4B/blob/main/LICENSE)，Apache 2.0。Unsloth 发布 GGUF 量化文件 | `licenses/Apache-2.0.txt`，量化来源、版本、文件大小与原始校验值见 `release-manifest.json` 的 `models` |

资料正文保留已有来源字段。R4 新增速查为原创整理，外部论文只保留链接，收录记录在 `docs/data/r4-curation.json`。此目录用于本地比赛机迁移；公开分发前请核对各原始资料的再分发许可。
