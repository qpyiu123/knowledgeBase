# 消逝的曲线：四个点足够恢复哪些参数

本地密码题。原附件见 第二轮测试清单中的 `curve-parameters`。已恢复本题的曲线参数，并验证全部四点。

## 先看这一步

先用四个平面点消掉常数项。交叉相乘得到若干模数倍数，从公约数恢复模数后再求曲线系数。

**适用时**：点在同一条短 Weierstrass 曲线上。 **留意**：公约数可能是模数的倍数，需检验位数和素性。

题目只打印四个形如 `(x : y : 1)` 的点。最后一个数是 1，所以前两个数就是平面坐标。源码说明曲线满足 `y² = x³ + a*x + b (mod p)`，且 `p` 是 160 位素数。

1. 每个点都能算出整数 `u = y*y - x*x*x`。取第一个点作为基准，其他点分别减去它，得到三组 `(dx, du)`。这时 `du ≡ a*dx (mod p)`，常数 `b` 被消掉了。
2. 任选两组，交叉相乘再相减：`dx1*du2 - dx2*du1` 必定是 `p` 的倍数。对三组两两组合的非零结果求最大公约数。这个公约数也可能比 `p` 大，要按 160 位、素数、坐标小于模数等条件确认。
3. 求到 `p` 后，用一组 `dx` 不为零的差值计算 `a = du * pow(dx, -1, p) % p`，再用第一个点得到 `b = (y0*y0 - x0**3 - a*x0) % p`。

最后把四点逐个代回，确认 `(y*y - x**3 - a*x - b) % p == 0`。本题还核对了 `4*a**3+27*b*b` 模 `p` 不为零，按附件指定的十进制字符串 `str(a+b+p)` 计算 SHA-256 即可生成题目答案。全程不用求点的倍数。
