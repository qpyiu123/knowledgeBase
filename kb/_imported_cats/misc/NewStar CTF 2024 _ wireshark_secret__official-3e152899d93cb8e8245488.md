## wireshark_secret

学会怎么从一个 HTTP 响应的流量中导出图片。

点击 `secret.png` 这个数据包。

左下角找到 File Data 这个字段，右键，点击导出分组字节流，然后文件保存为 PNG，就可以打开图片了。
