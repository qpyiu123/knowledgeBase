# 网鼎杯 2024 青龙/crypto001

> 赛事：网鼎杯 2024 | 方向：crypto | 难度：hard | 工具：Radare2、Z3

## 一句话总结

4 道 crypto 题合集：高位 p/q 还原 / p-1 smooth RSA / 双重签名 + Vigenère / SPN 分组密码

## 攻击链

1. crypto001: 给 n, e, c + hint1 = p>>442 + hint2 = q>>442 (各 70 bit 高位)
2. 已知 p/q 高位 → 构造 bd_attack (Coppersmith) 还原 p, q
3. 算 d = inverse(e, phi)，解 m = pow(c, d, n) 拿 flag
4. 白虎 crypto: 2g*a+1 形式素数生成，g 是 1000bit 素数
5. p-1 平滑 → Pollard p-1 分解
6. 双重签名泄漏 s = (z + r*dA % n) * k^-1 % n
7. 两组 (r1,s1) 和 (r2,s2) 已知 → 联立方程解 dA
8. 算 sha256(dA) → AES key → 解密 victory_encrypted_flag
9. Vigenère "WANGDINGCUP" 解回明文
10. SPN: P permutation + S 函数 + 14 轮 SPN 分组密码
11. 用 z3 求解 z3.add(encryptWithoutP(P(m), key) == P(c))

## 关键 payload

```
hint1, hint2 = p>>442, q>>442  # Coppersmith bd_attack 还原
```

## 经验教训

已知 p/q 高位 70bit 必用 Coppersmith bd_attack；2g+1 形式素数 p-1 平滑用 Pollard p-1；EC-Schnorr 双重签名同 k 联立解 d
