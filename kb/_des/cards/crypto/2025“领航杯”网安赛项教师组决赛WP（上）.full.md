# 2025"领航杯"网安赛项教师组决赛 WP（上）- Crypto 修栅栏/RSA + Misc DNS/FTP + Web locallogin

## 一句话总结

2025 领航杯教师组决赛上：Crypto 修栅栏+RSA + Misc DNS/FTP + Web locallogin XFF+cookie 替换+sqlmap。

## 攻击链

1. Crypto 修栅栏：三个一组替换，从上往下从左往右拼接 → CnHongKe base64 → 解码
2. Crypto RSA：直接参考 Python 脚本运行
3. DNS 流量：二级域名组成有意义语句 → flag
4. FTP 流量：flag.zip + sk.pem + secret.enc → 还原密文
5. Web locallogin: user/userpass 登录 + X-Forwarded-For: 127.0.0.1 绕 IP 检测
6. cookie base64 编码 user→admin 替换
7. Web sql: sqlmap 脚本爆破

## 关键 payload

```
X-Forwarded-For: 127.0.0.1 绕 IP 检测
```

## 经验教训

修栅栏密码 = 三组字符按行拼接 → base64 编码；X-Forwarded-For 绕 IP 检测是经典 Web 套路；base64 编码 cookie 替换 user 字段是 admin 鉴权绕过常考点。
