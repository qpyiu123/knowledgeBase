# 2024 数信杯北部赛区 WP（XTEA 字节码+Log4j+SSTV+取证实战+Solidity）

## 一句话总结

数信杯北部综合：XTEA 32 轮字节码逆向 + 凯撒+base64 + Log4j LDAP + SSTV 解码 + volatility Win7 取证 + frp socks5 + findwallet 钱包 + Solidity 漏洞；完整数据安全+取证+Web 三栈。

## 攻击链

1. 数据安全 Drinktea: python .pyc 字节码 dis 反编译 XTEA
2. XTEA encrypt: delta=555885348, 32 轮, v0 += ((v1<<4 ^ v1>>5) + v1) ^ (total+key[total&3] ^ v1)
3. decrypt 反向：v1 -= ... ; sum1 -= delta; v0 -= ...
4. flag2: 凯撒 shift=17 + base64 + chr(i) ^ 0x18
5. Misc sstv: sstv -d ctf.wav -o out.png
6. 取证: volatility Win7SP1x64 lsadump + netscan + filescan 找外联+exe
7. 钱包: npm install findwallet -g 扫比特币+以太坊钱包
8. 区块链: Solidity transferFrom 仅校验 owner 缺授权检查漏洞
9. 提权: chromium zsh SUID 提权
10. 数据库: pandas.read_excel 邮箱对比 mysql_data.txt

## 关键 payload

```
delta=555885348; sum1 -= delta; v1 -= (((v0<<4)^(v0>>5))+v0) ^ (sum1+k[(sum1>>11)&3])
```

## 经验教训

python 字节码 `dis` 反编译是 .pyc 还原源码最简方法；XTEA 的 delta 不一定是 0x9E3779B9，数信杯用 555885348 自定义 delta；frp/npc 代理的 socks5 plugin 容易暴露到外网（118.180.126.13:32124 是经典外联 IOC）。
