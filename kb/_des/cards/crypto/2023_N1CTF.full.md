# 2023 N1CTF

> 赛事：N1CTF 2023 2023 | 方向：crypto | 难度：hard

## 一句话总结

ECDSA nonce 拼接泄漏 + LLL/small_roots + ECPrng pqr 分解 + RSA Coppersmith。

## 攻击链

1. e2W@rmup: ECDSA 签名 nonce = msg前128 + d后128 拼接
2. 拆 d = dh<<128 + dl，s 与 r 满足 R*(2^128*r - s)*dh + R*(M*s - msg_hash) = k*order + dl + 2^128
3. 用 LLL 缩短向量解 dh 和 dl 高位部分
4. bruce1=bruce2=0b11<<126 锁定 d 已知高 2 bit 偏移
5. small_roots LLL m=3 d=4 恢复完整 d
6. long_to_bytes(d) 当 AES-ECB key 解密 flag
7. e20k: ECPrng 状态在 y^2=x^3+7 mod N，N=pqr 三素数
8. keygen 用 2q-1 prime + 2q^2-q 算术性质
9. Williams p+1 + 二次剩余分解 N
10. EN_random_element_k k=3 用 CRT 拼 EC 点
11. N1CTF{e20k...}flag
12. 第三题 RSA mask 加密，p,q 都是 256-bit 安全素数
13. Coppersmith 攻击爆破 mask

## 经验教训

ECDSA nonce = msg|d 拼接是经典坑，用 LLL + small_roots 联合爆破；N=pqr 复合模数用 2q-1 prime + Williams p+1 分解。
