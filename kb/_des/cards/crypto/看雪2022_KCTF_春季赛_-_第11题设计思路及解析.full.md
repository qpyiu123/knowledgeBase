# 看雪 2022 KCTF 春季赛 第11题 虫洞末世 ydmp 原点磨盘

> 赛事：KCTF春季赛 2022 | 方向：crypto | 难度：hard | 工具：Sage

## 一句话总结

ydmp 原点磨盘密码：平方+公倍数+浮点误差+暴力 96^4 组合，4 元变量 sage 因子分解 + GCD 求唯一解。

## 攻击链

1. flag = lrY1314cXy2920as
2. 数字映射 ascii+175, 字符映射 ascii+100
3. 平方组合: p = lists[2i]² * lists[2i+1] + i² (i = 项数)
4. 奇偶判定: 奇数 +2, 偶数 +1
5. 磨盘公倍数: 在第 3 式项数同乘的基础上分别相加得到 2.式的公倍数 Q
6. Q 作除得到最终值
7. 验证: 开放首末最终值 + 6 项的两两比值 doom 后的值
8. sage gcd(m0, m1) = 32, factor 拆解 m0 m1 为素因子
9. 暴力 96^4 = 8,419,072 组合 (i,l,j,m) 找 (197,215) (208,214)
10. 浮点运算 + doom 误差扩大 → 整数比较容差

## 关键 payload

```
p = lists[2i]² * lists[2i+1] + i² + 平方公倍数 + 浮点 doom 误差
```

## 经验教训

自定义数学密码的破解依赖 gcd/factor + 暴力枚举；浮点误差处理是工程关键。
