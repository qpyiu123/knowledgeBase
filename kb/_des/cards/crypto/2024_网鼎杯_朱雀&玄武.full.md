# 2024 网鼎杯 朱雀 & 玄武

> 赛事：网鼎杯 2024 | 方向：crypto | 难度：hard

## 一句话总结

Coppersmith 已知 p 高位 + 多层 RSA 套娃 + Shamir kernel 攻击。

## 攻击链

1. 朱雀 crypto002: 已知 p 高 256bit → Coppersmith X=2^248 beta=0.49 epsilon=0.014 → 爆破 7 比特 p / crypto003: 3 层 RSA 套娃 - Layer1: n1=p1*q1 q1=next_prime(2024*p1) → n1//2024 开根还原 p1 / Layer2: n2=p2*q2, n22=p2^2+q2^2 → 解二元二次方程 (p2+q2)^2 = n22+2n2, (p2-q2)^2 = n22-2n2 / Layer3: p3/q3 共享 1024 高位 → 已知 p3 高位攻击 / 两式 m1=p1*m^2+p2*m+p3, m2=q1*m^2+q2*m+q3 → 解联立方程 / 玄武 Shamir: 10000 份 shares 每份 64 个 polynomial coefs + value, n_players=64, threshold=128 > 实际自由度 32 → 拆 32 维 kernel (C2 = matrix of high coefs) → 累积 C1*kernel 拼出完整矩阵 → 求解

## 关键 payload

```
f = (p>>248)<<248 + x ; f.small_roots(X=2^248, beta=0.49, epsilon=0.014) ; n1 // 2024 开根 = p1 ; m^2 = p1*m1 - p2*m + p3 / p1 ; ShamirSS(coefs, value) 64 个 coefs, 10000 组
```

## 经验教训

Shamir 秘密共享若 threshold > 自由度，攻击者可取 C2 矩阵求 kernel 还原 C1 拼出完整方程组。
