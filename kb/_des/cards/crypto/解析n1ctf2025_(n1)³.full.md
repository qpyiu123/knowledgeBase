# n1ctf 2025 Crypto (n1)³ 张量分解攻击

> 赛事：n1ctf 2025 | 方向：crypto | 难度：hard

## 一句话总结

n1ctf 2025 Crypto 高难度：把 35 维立方加密视为对称张量 f(x) = Σ w_k (v_k^T x)³，用 Jennrich 算法做 CP 分解恢复明文。

## 攻击链

1. enc(x) = (xU)^{[3]} · T，35 维 FLAG 用 .digits(257) 编码为 35 个 0-256 数字
2. 35 个三次多项式 = 35 个输出维度，每个 f_i(x) = Σ(j,k,l) S[i,j,k,l] · x_j x_k x_l
3. 构造对称张量 S，使 f(x) = Σ_k w_k (v_k^T x)³
4. Jennrich 算法：随机收缩 a, b ∈ GF(257)^n，构造 A = S_c ×_3 a, B = S_c ×_3 b
5. X = A B^(-1)，扫 t ∈ [0,256] 找 det(X - tI) = 0 收集特征值
6. 零空间求特征向量 v_k，归一化使首非零分量为 1
7. 解 W：A_rows = V^∘³ W（只有常数项与 x_j³ 在 e_j 处存活），W = (V^∘³)^(-1) A_rows
8. 验证：f(x) ≟ W (V^T x)^∘³ (mod 257)
9. 解 u³ = (W^T)^(-1) y
10. 开三次方：u = pow(u³, inv3, 257)，inv3 = 171 (因为 3*171 mod 257 = 1)
11. 解 V^T x = u，组装 35 个 0-256 数字 → bytes → FLAG

## 关键 payload

```
enc(x) = (xU).apply_map(c^3) * T，GF(257)，35 维 FLAG，Jennrich CP 分解
```

## 经验教训

张量密码学的安全性依赖维度与域大小，Jennrich 算法的 O(n³) 复杂度在 GF(257) 上对 n=35 完全可行；GF(p) 立方根唯一（p 满足 3 ∤ (p-1)）。
