# 2025 第三届熵密杯（SM2+SM4+SM3 EnvelopedData PKCS7 国密）

> 赛事：2025 第三届熵密杯 2025 | 方向：crypto | 难度：hard

## 一句话总结

2025 熵密杯 SM2+SM4+SM3 国密 EnvelopedData PKCS7 封装：sm2 加密 sm4 key + sm4-cbc 加密明文 + sm3 摘要 + pyasn1 DER 编码。

## 攻击链

1. EnvelopedData = SM2Cipher (x, y, hash, cipherText) + EncryptedData (SM4-CBC iv, ct) + SM3 digest
2. SM4 key 从 key.txt 读，固定密钥
3. sm2_encrypt(sm4_key, public_key) → x(32)+y(32)+hash(32)+cipherText(...)
4. sm4_cbc_encrypt(plaintext, sm4_key, iv, nopadding) → ct
5. sm3_hash(plaintext) → digest
6. 攻击：已知 plaintext 字典（如 a/b/c/d 组合），遍历爆破

## 关键 payload

```
EnvelopedData = SM2Cipher(encryptedKey) + EncryptedData(cipherText) + SM3 digest
```

## 经验教训

国密 PKCS7 EnvelopedData 是中国密码标准封装结构，OID 1.2.156.10197.1.104.2 = SM4-CBC，1.2.156.10197.1.401.1 = SM3；gmssl 库是国内国密算法事实标准。
