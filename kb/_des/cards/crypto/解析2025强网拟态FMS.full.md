# 2025 强网拟态 FMS - LCG PRNG 状态恢复攻击

> 赛事：强网拟态 2025 | 方向：crypto | 难度：hard | 工具：Python

## 一句话总结

LCG 后门泄露参数 + 128 字节低 8 位泄漏用 LLL 格基规约恢复 128 位种子，复现 admin 密码。

## 攻击链

1. 目标: Python 写的 Flag 管理系统 main.py，含 [L]ogin / [G]et Public Key / [R]ead Flag / [E]xit
2. 漏洞: Get Public Key 后门泄露完整 LCG 参数 a, b, p
3. 状态: state_{n+1} = (a × state_n + b) mod p，128 位素数
4. 关键: 每次 randbytes 输出 PRNG 状态低 8 位，登录失败不影响 PRNG 状态
5. 通过多次登录失败收集 128 个低 8 位样本
6. 用 LLL 格基规约恢复 128 位初始种子
7. 格构造: 每次观测 T_i = state_i mod 256，state_i = a^i × s + b × Σ(a^j) mod p
8. LLL 找短向量 = 满足所有约束的解 = 正确种子
9. 复现 PRNG 生成 admin 密码
10. 登录 admin 读 flag

## 关键 payload

```
state_{n+1} = (a × state_n + b) mod p + 128 字节低 8 位 + LLL 恢复
```

## 经验教训

LCG 的低 8 位 + 参数 + 足够样本可被 LLL 还原完整状态；Get Public Key 是典型后门设计。
