# 2023 江苏省首届数据安全竞赛

> 赛事：江苏省首届数据安全竞赛 2023 | 方向：crypto | 难度：hard

## 一句话总结

RSA e=13 低指数广播 + hint 填充 + Coppersmith 解小根分解模数。

## 攻击链

1. day() 生成 5 个 30-40 bit 随机数 A
2. hint = str(A)[1:-1].replace(', ', '||').encode() ≈ 560 bit
3. 5 个 pubkey 都是 e=13，n 不同
4. hint2 = bytes_to_long(pad(hint)) = hint1 * pad（pad 已知高位）
5. 对 c_i = pow(hint, 13, n_i) 走处理 c_i * pow(pad, -13, n_i) % n_i
6. CRT 合并 → iroot(13) → hint 还原 A
7. night() 生成 p,q 1024 bit
8. core = 70-80 bit 随机数
9. box = (A[4]*p^4 + A[3]*p^3 + A[2]*p^2 + A[1]*p + core) % n
10. shell = (A[4]*box^4 + A[3]*box^3 + A[2]*box^2 + A[1]*box + A[0]) % n
11. 拆 shell 方程得 p 关系式，mod p 下用 Coppersmith 解小根
12. 还原 p 后解 n 得 q，标准 RSA 解密

## 关键 payload

```
pubkeys e=13, 5 个不同的 1024-bit n, package = 5 个密文
```

## 经验教训

pad 函数只在尾部填 0 可让 hint2 = hint1 * pad 高位已知；Coppersmith 适合解模 p 下的小根恢复 p 关系式。
