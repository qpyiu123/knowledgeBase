# 2024 网鼎杯 半决赛 & 决赛

> 赛事：网鼎杯 2024 | 方向：crypto | 难度：hard

## 一句话总结

p 高位 Coppersmith + LFSR+NFSR 序列密码 + 有限域同构 AES key 还原。

## 攻击链

1. 半决赛 RSA: 已知 p 高 256 bit + (p>>248)<<248 → Coppersmith X=2^248 beta=0.49 → 爆破 7 bit 还原 p 完整 512 bit → 1.7% 成功率 / 序列密码: LFSR(12bit seed/mask) + LFSR + LFSR + NOISE 12bit → 每局 512 次请求 128 字节密文流 → 多次采样求 noise 期望 → 还原 12bit 噪声 + 2 个 128bit LFSR / 决赛 piff: 41 元域 F_41^128 三个不可约多项式 f/F1/F2 + 2 个同构映射 φ1/φ2 + AES-ECB 加密 flag → 找 φ1,φ2 的逆映射 + 复合 GCD 还原 m → 二元域上取系数转 AES key

## 关键 payload

```
f = (p>>248)<<248 + x ; f.small_roots(X=2^248, beta=0.49, epsilon=0.014) ; noise bit = 1/3 prob when lfsrn=1, 2/3 prob when lfsrn=0 ; CompositeFieldElement F1(a) = F2(b) → GCD(φ1 - 1, φ2 - 1) 还原 primitive
```

## 经验教训

Coppersmith 攻击当 p 已知 256/512 bit 时爆破 7 bit 是 38 分钟；有限域同构问题本质是 GCD。
