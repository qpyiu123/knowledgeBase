# 2025 年能源网络安全大赛团体预赛（背包密码 eazy_crypto + 超递增序列还原）

> 赛事：2025 能源网络安全大赛 2025 | 方向：crypto | 难度：medium

## 一句话总结

2025 能源预赛 eazy_crypto：背包密码 + 超递增序列 LLL 还原 + mod b 恢复 private_key + 贪心解子集和。

## 攻击链

1. flag = bin(int.from_bytes(flag, 'big'))[2:] 二进制展开
2. private_key = [g, 2g, 4g, ...] 超递增序列
3. public_key = (a * private_key) % b
4. c = sum(flag[i] * public_key[i])
5. 攻击：LLL 还原超递增序列 → mod b 还原 private_key
6. 求 a_inv = inverse(a, b) → private_key = (public_key * a_inv) % b
7. 超递增序列求和（从大到小贪心）→ flag bit
8. flag = long_to_bytes(int(flag_bin, 2))

## 关键 payload

```
private_key[i] = (public_key[i] * inverse(a, b)) % b
```

## 经验教训

背包密码（Merkle-Hellman）= 超递增序列 + 模 b 乘 a 混淆 + 模 b 求逆还原 + 子集和贪心；a*b 都是素数是攻击前提。
