# 工业信息安全技能大赛复赛 - 海南车联网/信创密码题

> 赛事：工业信息安全技能大赛复赛(海南) 2024 | 方向：crypto | 难度：hard

## 一句话总结

工业信息安全复赛车联网3题:功耗分析ByPass/手动CPA攻击AES-128/DH+SHA256+AES-CBC解密。

## 攻击链

1. XA_CTF_ByPass:npz index/input/trace → 11组×40字符 → np.mean(trace[i:i+40], axis=0) → corrcoef(trace[j], avg_trace)[0][1] < 0.5 → 找特立独行 → XA_CTF_AES128:50组input/output/trace + CPA相关性能量分析 + AES第一轮输出汉明重量 → tbox:DH私钥+模数+流量包公钥密文 → pow(g,5272,p)得512bit key → sha256→AES-128-CBC iv=0

## 关键 payload

```
corrcoef<0.5 + AES-128 CPA + DH pow(g,5272,p) + sha256(key)+AES-CBC(iv=0)
```

## 经验教训

侧信道功耗分析找异常字符用corrcoef阈值0.5;AES-128 CPA看第一轮SBox输出与功耗相关性;RSA功耗分析倍增法:5针脚=1,3针脚=0,根据窗口200分段提取私钥;DH协商密钥sha256后作为AES-CBC iv=0密钥;车联网+信创双模块。
