# 2024 KCTF 大赛 - 第五题《废弃星球》设计思路及解析

> 赛事：KCTF大赛 2024 | 方向：crypto | 难度：hard | 工具：Rust

## 一句话总结

BF-IBE + HMAC 密钥等价伪碰撞 + BLS12-381 光滑子群攻击 + LSB 多次 reset 拼方程。

## 攻击链

1. Rust 逆向 + pairing-ce 库 → 找到 BF-IBE 标准实现 → HMAC 伪碰撞 admin@pubkey.com + \x00 等同私钥 → 拿到 admin 凭证 → blind_recovery 输入自定义 x 坐标 → 服务端未校验 256-bit 素数阶子群 → 选光滑子群 64-bit Pohlig-Hellman 爆破 d 模 64bit → 三次 reset_system(mul) 重置 PKG 私钥 d → LSB Leak 类比 RSA-LSB 拼多组方程恢复 d → 拿 flag
