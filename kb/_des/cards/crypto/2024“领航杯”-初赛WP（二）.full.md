# 2024"领航杯"-初赛WP（二）

> 赛事：领航杯 2024 | 方向：crypto | 难度：medium

## 一句话总结

RSA p^4+tp AMM 开方 + 身份证校验和提取 + web sum 哈希碰撞。

## 攻击链

1. 1. CRYPTO_Evaluate: p=p^4+tp (512-bit随机p+20-bit小扰动tp) → AMM 开方 (p^4 mod n) 拿 p / 2. MISC-veee: 1W 个身份证号 → 提取校验位不对的 → 转 ASCII → base64 隐写 / 3. WEB_ACXI_: 注册 test/123456 → 服务器加和 ord(c) 当 hash → 爆破 0x202f5 = 131829 → 多个 7 字符密码 sum 匹配 0x0202f5 → 绕过 admin 校验

## 关键 payload

```
p, tp = genPrime()  # p^4 + tp 素数 ; AMM(p^4 mod n) 拿 p ; this_is_pwd_j71nas2 ; 0x202f5 = 131829 ; sum(ord(c) for c in ''test123456'') = 0x2f5
```

## 经验教训

p^4+tp 模数可对 p^4 用 AMM 开方求 p 候选；web 弱哈希常是 sum(ord) 单值校验。
