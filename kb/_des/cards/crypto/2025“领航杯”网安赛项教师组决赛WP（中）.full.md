# 2025"领航杯"网安赛项教师组决赛 WP（中）

> 赛事：领航杯 2025 | 方向：crypto | 难度：medium | 工具：PHP

## 一句话总结

公众号风格的两题展示 — Crypto-randError 现场无人解，MT19937 逆推 + AES-ECB 明文前缀爆破；Misc-VC&EZ 提示恶意 docx + 符号链接 + PHP filter 链读 flag。

## 攻击链

1. 拆解 Xorshift32 4 段位移掩码 (>>18/<<15/<<7/>>11)
2. 用 inv_number 还原 update_state 前置 MT-like 状态
3. gen_rand_number 模拟末端正向
4. 多进程分片穷举 S 状态 0..2^32
5. AES-ECB 解密 ciphertext 验证 "CnHongKe" 前缀

## 关键 payload

```
MT19937 逆运算 + multiprocessing 32-bit 状态分片爆破
```

## 经验教训

完整 EXP 被作者隐藏成引流钩子；MT19937 状态可逆可爆破前提是 update_state 是仿射的且 y*X 段可枚举。
