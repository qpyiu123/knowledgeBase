# 强网杯 谍影重重5.0

> 赛事：强网杯 (Qiangwang) 2024 | 方向：forensics | 难度：hard | 工具：hashcat、tshark

## 一句话总结

NTLMSSP 离线爆破 + SMB 会话密钥解密 + RDP 键盘还原

## 攻击链

1. tshark 提取 NTLMSSP NTLMv2 认证字段
2. hashcat -m 5600/rockyou 爆破 tom 密码 babygirl233
3. MD4+HMAC-MD5 推 responseKey/keyExchangeKey
4. ARC4 解密 SMB session key 解密后续 SMB 流量
5. tshark 提 rdp.fastpath.scancode.keycode 还原键盘记录

## 关键 payload

```
tom::.:c1dec53240124487:ca32f9b5b48c04ccfa96f35213d63d75:0101...2900
```

## 经验教训

pcapng 含 NTLMv2 时可直接 hashcat 爆破密码；session key 解密后才有 SMB 流量；RDP fastpath scancode 是键码记录可还原键盘输入
