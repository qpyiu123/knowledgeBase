# 2025 西湖论剑决赛 misc 全解

> 赛事：西湖论剑 2025 | 方向：forensics | 难度：medium

## 一句话总结

西湖论剑决赛 misc — R-Studio 恢复 + 文件名拼 zip + 冰蝎3/4 流量 AES 解密 + 拼图 + RC4 像素级解密 + 盲水印。

## 攻击链

1. 用 R-Studio 提取镜像得到目录 "The flag is here
2. 文件夹按 mtime 排序, 各自 basename[0] 拼接 → binascii.unhexlify 得 flag.zip
3. 冰蝎3 + 冰蝎4 流量: 先解冰蝎4 得 XOR 密钥 → 解冰蝎4 流量得到 she1l.php 冰蝎3 脚本
4. 冰蝎3 批量 AES-CBC (iv=16*0x00, key="5b4582c9d56b5b33") 解密每行 base64
5. 二次 base64 解码得到 PNG 切片
6. 拼图得到 Steganography_challenges0.3.png
7. 用 RC4 ("password") 逐像素 RGB 解密得新像素
8. 最后盲水印提取 flag

## 关键 payload

```
mtime排序+basename[0]拼hex→zip / 冰蝎4 XOR key "5b4582c9d56b5b33" / RC4 key "password" 逐像素 / 盲水印
```

## 经验教训

目录名拼 zip 需按 mtime 排序再 unhexlify；冰蝎4 → 冰蝎3 链路是先解冰蝎4 得 key 再解冰蝎3 得 shell；RC4 逐像素解密需逐字节处理 RGB。
