# 2023 年全国网络安全行业职业技能大赛 - 电子数据取证分析师（淘汰赛 C 卷）- WP

> 赛事：2023 全国网络安全行业职业技能大赛 2023 | 方向：forensics | 难度：medium | 工具：C

## 一句话总结

取证淘汰赛 C 卷 5 检材：ext4+E01+监控+宝塔面板 综合 20 题。

## 攻击链

1. 检材 1 ext4 文件系统，Asia/Shanghai 时区，IMEI 提取
2. HL1sbetter WiFi 密码
3. 检材 2 E01 镜像 SHA-1 计算
4. 检材 3 远程登录 IP + 服务器关机时间
5. 网站路径 + 数据库配置文件路径
6. 检材 4 监控厂商识别 + 格式化时间
7. 起始扇区 + 数据块大小
8. 检材 5 系统版本号 + 命令历史第 11 条
9. 第一次登录 IP + 宝塔面板密码
10. 虚拟货币诈骗网站源码 + 联系人手机号

## 关键 payload

```
检材 1: ext4 / Asia/Shanghai / HL1sbetter
```

## 经验教训

监控厂商识别靠字符串匹配；宝塔面板默认密码在 config.json；命令历史第 11 条要按序号精确定位。
