## 一句话总结

首届盘古石杯全国电子数据取证大赛总决赛-数据分析:copy *.csv Merged.csv+SQL SUM CASE WHEN+NULLIF+COUNT(DISTINCT)聚合查询银行卡交易(进/出/比/总额)

## 攻击链

1. 1. copy *.csv Merged.csv 合并多个CSV|2. 转入对手去重统计+转出对手去重统计+特定卡号(6233542760791453)转入转出比|3. 全卡号按转出比排序DESC|4. 按转入成功总额排序

## 关键 payload

```
copy *.csv Merged.csv|SELECT COUNT(DISTINCT 交易对手账卡号) FROM Merged WHERE 交易是否成功 = 1 AND 收付标志 = '进'|SELECT COUNT(DISTINCT 交易对手账卡号) FROM Merged WHERE 交易是否成功 = 1 AND 收付标志 = '出'|SELECT SUM(CASE WHEN 交易是否成功 = 1 AND 收付标志 = '进' THEN CAST(交易金额 AS FLOAT) ELSE 0 END) AS 转入成功, SUM(CASE WHEN 交易是否成功 = 1 AND 收付标志 = '出' THEN CAST(交易金额 AS FLOAT) ELSE 0 END) AS 转出成功, SUM(...)/SUM(...) AS 转出比 FROM Merged WHERE 交易卡号='6233542760791453';|SELECT 交易卡号, SUM(CASE WHEN 交易是否成功 = '01' AND 收付标志 = '进' THEN CAST(交易金额 AS FLOAT) ELSE 0 END) AS 转入成功, ... SUM(...)/NULLIF(SUM(...), 0) AS 转出比 FROM Merged GROUP BY 交易卡号 ORDER BY 转出比 DESC|SELECT 交易卡号, SUM(CASE WHEN 收付标志 = '进' AND 交易是否成功 = '01' THEN CAST(交易金额 AS FLOAT) ELSE 0 END) AS 转入成功总额 FROM Merged GROUP BY 交易卡号 ORDER BY 转入成功总额 DESC
```

## 经验教训

1) 多个CSV合并:Windows copy *.csv Merged.csv;2) SQL聚合:COUNT(DISTINCT)去重+SUM(CASE WHEN条件聚合;3) NULLIF(SUM(...), 0)防除0;4) 转出比=SUM(出)/SUM(进);5) ORDER BY DESC排序
