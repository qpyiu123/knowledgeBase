# 2023 江苏省数据安全竞赛 决赛

> 赛事：江苏省数据安全竞赛 2023 2023 | 方向：forensics | 难度：medium | 工具：ThinkPHP、netcat

## 一句话总结

哥斯拉 webshell 流量解密 + AES md5 爆破 5 位 hex key + 内存取证 + 框架版本还原。

## 攻击链

1. 流量包 67 流：哥斯拉 webshell 自定义 XOR 加密 (key=6cfcfe9b99c68a0a)
2. dec 函数 c[i] ^ key[(i+1)&15] + base64 + gzip 解压
3. 获取受害服务器上游 IPv6 地址 fd15:4ba5:5a2b:1008:60b9:ff63:528e:149d
4. 流量 23 流 AES-256-CBC iv+ct 拼接，md5(5位hex) 爆破 key
5. key=61c42 还原出 zip -P SN@jSoiueFIEZSIDJ 打包
6. 流量 76 流另一份加密 bash reverse shell → 114.5.1.211:42321
7. 第 2 个 key=23b4d 爆破 ThinkPHP 框架 version.zip 密码 MS1209D@IOEJabnsdIUJEOI@
8. 答案：nginx:1.22.1_8.1.17_thinkphp:6.0.12
9. volatility 内存镜像 Win7SP1x64 netscan 找 nc.exe 外连 192.168.233.1_54266
10. Passware Kit Forensic 爆破 BGS-Chenyi 开机密码 abc123456
11. memdump -p 3036 搜 LOGONSERVER = BGS-CHENYJ-PC

## 关键 payload

```
iv + ct 模式：AES-256-CBC, iv[:16] + ct[16:]
```

## 经验教训

哥斯拉 webshell 加密模式 = XOR(16 byte key) + base64 + gzip；AES-CBC key 爆破 = md5(hex(i).rjust(5,'0'))。
