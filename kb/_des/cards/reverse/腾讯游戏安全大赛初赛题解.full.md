# 腾讯游戏安全大赛初赛题解

> 赛事：腾讯游戏安全 2023 | 方向：reverse | 难度：medium

## 一句话总结

腾讯游戏安全初赛：CE 找 base64 表 + 找明文 + DLL 注入 PATCH 内存让 Base64 密文改明文，NOP 关键指令 + 修复 inline hook。

## 攻击链

1. Q1 找明文: 64 位 Windows10 + contest.exe + 写 contest.txt
2. 密文: ImVkImx9JG12OGtlImV+
3. 用 Cheat Engine memory view 找 contest.txt 字符串
4. 找 base 表地址 7FF713657190: QRSTUVWXYZabcdefABCDEFGHIJKLMNOPwxyz0123456789+/ghijklmnopqrstuv
5. base64 解密得 catchmeifyoucan (明文)
6. Q2 改内存让密文改明文:
7. base64 三原文对应四密文规则
8. 右移两位查表 = 第一密文 → NOP 掉 contest.exe+BA39~BA41
9. and 0x3f = 第四密文 → NOP 掉 contest.exe+B9FD~BA04
10. 第三项目 BA5D~BA68 NOP 掉
11. mov [r14],al + add r14,0 (不递增 r14) → BA05 起始
12. VirtualProtect 被 inline hook → 修复 ZwProtectVirtualMemory
13. VirtualProtectEx + WriteProcessMemory PATCH 内存
14. 远程线程注入 DLL → LoadLibraryA → DllMain → patch()

## 关键 payload

```
NOP contest.exe+BA39~BA41/B9FD~BA04/BA5D~BA68 + BA05 mov [r14],al + add r14,0 + DLL inject
```

## 经验教训

Windows inline hook 修复是高级游戏安全技术；DLL 注入 + WriteProcessMemory 是游戏外挂标配。
