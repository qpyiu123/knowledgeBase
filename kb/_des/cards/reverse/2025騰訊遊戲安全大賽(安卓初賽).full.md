# 2025 騰訊遊戲安全大賽 (安卓初賽)

> 赛事：腾讯游戏安全 2025 | 方向：reverse | 难度：hard

## 一句话总结

腾讯游戏安全安卓初賽 — UE4 + Disable Depth 透视 + LineTrace 渲染控制 + pthread_create 钩子 anti-bypass + RecoilPitch 改 0 去后座 + 多个 libUE4.so 偏移 aimbot 替代实现。

## 攻击链

1. Disable Depth Test + Custom Depth 渲染通道切换: 透视
2. LineTraceSingle(FirstPersonCharacter_C, ThirdPersonCharacter_C) → HitResult.Distance=0 即不被遮挡
3. HitResult.Distance==0 时把 ThirdPersonCharacter_C 不渲染到 MainPass
4. 子彈只射腳底才有碰撞
5. pthread_create 钩子: 拦截 libGame.so+7068 偏移的线程 (anti bypass), 其他原样
6. CharacterMovementComponent +0x1a0/0x18c 改 MaxWalkSpeed/Acceleration=1e9 → 飞天
7. MyProjectCharacter 0x528 bUsingMotionControllers / 0x52c RecoilPitch / 0x530 RecoilYaw / 0x534 RecoilRecoverySpeed / 0x538 RecoilAccumulationRate 改 0 → 去后座
8. patch libUE4.so+0x8B3861C (mb_aimbot) → NativeCallback 替代实现
9. hook libUE4.so+0x6711D34 (OnHit) 打印 camera rotation
10. patch libUE4.so+0x670F110 → 始终返回 1 (某种 boolean check)
11. hook libUE4.so+0x680B790 → 看到 "BigWall" uobj 名 (疑似 wallhack 检测点)

## 关键 payload

```
pthread_create 钩子 7068 / CharacterMovementComponent +0x1a0 MaxWalkSpeed / MyProjectCharacter 0x528 bUsingMotionControllers / RecoilPitch 0x52c / aimbot patch 0x8B3861C / 0x670F110 返回 1 / 0x680B790 BigWall wallhack
```

## 经验教训

UE4 安卓反作弊常驻检测 libGame.so+7068 偏移线程；MyProjectCharacter 0x52c RecoilPitch 0x530 RecoilYaw 0x534 RecoverySpeed 0x538 AccumulationRate 是去后座经典位；aimbot 用 NativeCallback patch libUE4.so 关键函数比写一整套目标追踪更稳定。
