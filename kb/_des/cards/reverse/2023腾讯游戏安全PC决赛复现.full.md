# 2023 腾讯游戏安全 PC 决赛复现 - Detours Hook + TLS 守护

> 赛事：腾讯游戏安全 PC 决赛 2023 | 方向：reverse | 难度：hard

## 一句话总结

Detours inline hook + TLS 计数 + CreateRemoteThread 远程注入的游戏反外挂守护。

## 攻击链

1. 用 CreateToolhelp32Snapshot 枚举 WorkingService.exe 进程 → OpenProcess + VirtualAllocEx 远程分配 → WriteProcessMemory 写 DLL 路径 → CreateRemoteThread + LoadLibraryA 注入 → DLL 入口 DllMain 用 Detours 库 inline hook CreateFileA → TLS 记录每线程调用次数超 16 次 ExitThread(0) 自杀 → 配合 ntdll.NtProtectVirtualMemory 0xA0990 偏移的 unhook 还原 originBytes 24 字节特征码

## 关键 payload

```
jmpBytes = { 0xE9, 0xE0, 0x26, 0x16, 0x00 } ; originBytes = { 0x4C, 0x8B, 0xD1, 0xB8, 0x50, 0x00, 0x00, 0x00, 0xF6, 0x04, 0x25, 0x08, 0x03, 0xFE, 0x7F, 0x01, 0x75, 0x03, 0x0F, 0x05, 0xC3, 0xCD, 0x2E, 0xC3 } ; unHookAddr = ntdll_base + 0xA0990
```

## 经验教训

Windows Hook 反外挂关键在 ntdll 自身也被 hook 时需要 unhook 后再注入，特征码恢复靠写死 24 字节 syscall 入口。
