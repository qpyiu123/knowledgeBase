# 2024 KCTF 大赛 - 第十题《试探》设计思路及解析

> 赛事：KCTF大赛 2024 | 方向：reverse | 难度：medium | 工具：IDA、Python

## 一句话总结

shellcode 拼图游戏 + 0 元素轨迹做注册码 + 6 字节花指令去混淆。

## 攻击链

1. IDA 看 main 调 NtAddBootEntry + TpAllocWait + TpSetWait → 怀疑 shellcode 注入 → 找到 6050 处的 shellcode 复制到 75C0 → 创建 2 线程跑 shellcode + 等待答案 → shellcode 有大量花指令（FD EB 1F 3E 1C EB EB 等 6 字节无效）→ 写 1.py 替换无效指令为 NOP → 写 2.py 还原 0x2A → 0x00 → 看到 3x3 拼图算法 → 0 在初始 {0,1,3; 5,2,6; 4,7,8} → 目标 {1,2,3; 4,5,6; 7,8,0} → 0 元素每次移动的索引就是注册码

## 关键 payload

```
011110202122 ; 3 字节无效指令 FD EB 1F 3E 1C EB EB / FF EB 15 3E 1D EB FB / FE EB 18 3E 1C EB EB ; 初始棋盘 {0,1,3;5,2,6;4,7,8} ; 目标 {1,2,3;4,5,6;7,8,0}
```

## 经验教训

无效指令 NOP 替换 + 0x2A 字节还原是 shellcode 混淆常见两步。
