# 2025 腾讯游戏安全技术竞赛 - 安卓初赛

> 赛事：腾讯游戏安全 2025 | 方向：reverse | 难度：medium

## 一句话总结

虚幻引擎 4 安卓手游 — Frida 写 GWorld/GName/GObjects 全局+解析 UObject+改 FirstPersonCharacter GunOffset + PlayerController Rotation + 透视 RenderCustomDepth bit3。

## 攻击链

1. 用 Frida 找到 GWorld (0xAFAC398) / GName (0xADF07C0) / GUObject (0xAE34A98) 三个全局
2. 解析 GName 池 FNamePool + FNameEntry (FNameStride=0x2, offset_FNamePool_Blocks=0x10, LenBit=6)
3. 解析 UObject: ClassPrivate 0x10 / FNameIndex 0x18 / OuterPrivate 0x20
4. 拿到 FirstPersonCharacter_C 0x500 偏移写 GunOffset → 自瞄
5. 拿到 PlayerController 0x288 偏移写 ControlRotation → 锁头
6. hook moduleBase+0x8D2ED80 函数 (CameraUpdate?) 用 PlayerController 的 rotation 覆盖 args[3]
7. RenderCustomDepth 0x212 第 3 bit 控制透视 → 全 actor 遍历打开

## 关键 payload

```
GWorld=0xAFAC398 / GName=0xADF07C0 / GObjects=0xAE34A98 / 0x288=ControlRotation / 0x500=GunOffset / 0x212=RenderCustomDepth
```

## 经验教训

UE4 安卓游戏逆向需先定位三大全局 (GWorld/GName/GObjects)；UObject 通过 FNameIndex 走 GName 池；Actor 偏移 0x288/0x500 是 ControlRotation 和 GunOffset 经典位置。
