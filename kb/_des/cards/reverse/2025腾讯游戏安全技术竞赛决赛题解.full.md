# 2025 腾讯游戏安全技术竞赛 - 决赛题解

> 赛事：腾讯游戏安全 2025 | 方向：reverse | 难度：hard | 工具：Python

## 一句话总结

Windows 内核 VT 抗分析 — kdcom.dll 检测 + KdDisableDebugger + VT hook TEA + MSR(0xE8) 异或 + Unicorn 模拟还原 + dfs(44,22) 记忆化变种。

## 攻击链

1. kdcom.dll 模块存在性检测 → hook NtQuerySystemInformation 把 Name[0] 改 'x' 隐藏
2. KdDisableDebugger 后台线程调用 → 驱动层直接 return 阻断
3. 读 flag 后做单表替换 (VT 实现, hook+0x95DF)
4. 用 key XOR flag 加密
5. 启用 VT 用 hook 过的 TEA 加密上一步密文
6. 改 rdmsr(0xE8) 行为, 在 check 前 XOR 一个由 flag 长度决定的 key
7. XSafe 驱动+二次加载: 用 XSafe.sys 加载, XSafe2.sys 用于定位 TEA 函数 dump enc.bin
8. VT-Detection1: MSR 检测源码
9. VT-Detection2: 真机专属检测
10. exp.py 还原 TEA 加密: Unicorn 跑 0xFFFFF806FF8D9F0C..0xFFFFF806FF8DA05C 提取栈明文
11. dfs 变种: f[x][y] = x%5 + dfs(x-1,y) + dfs(x-1,y-1); dfs(44,22)=7039739125714

## 关键 payload

```
kdcom.dll 检测 + KdDisableDebugger + VT hook TEA + rdmsr(0xE8) 异或 + Unicorn 模拟还原明文
```

## 经验教训

抗分析是分层叠加：模块名检测 + 调试 API 检测 + VT 虚拟化 + 硬件断点检测；XSafe 双驱动配合可定位+dump 被保护函数 enc.bin；Unicorn 模拟内核函数可旁过 anti-dump。
