# 看雪·众安 2021 KCTF 秋季赛 第四题 偶遇棋痴

> 赛事：KCTF秋季赛 2021 | 方向：reverse | 难度：hard | 工具：ARM、C、Unidbg、Z3

## 一句话总结

把 flag 验证逻辑用 Lambda 演算写出来序列化到 Android JNI，逆向时要还原 Lambda 语法树并独立爆破每个 4bit 输入。

## 攻击链

1. 出题方用 Lambda 演算（Church Numeral + ADD/SUB/MULT/IF/XOR/ABSDIFF）编码 flag 校验逻辑
2. 程序把 Lambda 表达式预编译后用 Boost text_oarchive 序列化到 C 字符串数组
3. 运行时反序列化回 Lambda 语法树
4. 用户输入 14 字符按 4bit 拆成 28 个 ipt
5. 把 28 个 ipt 插入预编译树的 28 个分支点
6. 调用 sub_39614 对整棵树做删减
7. 最终树只剩 3 个特定节点即通过
8. 关键：用户每个 4bit 输入对其他输入独立，可分 28 个独立 4bit 暴力（实际先低 4bit 后高 4bit）

## 关键 payload

```
flag = (high4bit << 4) | low4bit, 28 个方程 z3 解 + 暴力枚举
```

## 经验教训

Lambda 演算 + 序列化是隐蔽的"代码即数据"反模式，逆向者要么反序列化还原 AST（方式 1），要么爆破每个独立分支（方式 2）。
