# 2024 长城杯初赛 RE（easyre SSE 异或链）

> 赛事：2024 长城杯初赛 2024 | 方向：reverse | 难度：easy

## 一句话总结

长城杯 easyre：43 字节 input 自异或链 + SSE _mm_cmovemask_epi8 == 0xFFFF 校验 32 字节，爆破 1 字符逆推。

## 攻击链

1. 43 字节 input，循环 i ∈ [0, 43)
2. input[i] ^= input[i+1-42*(i+1/42)]
3. i < 41: input[i] ^= input[i+1]（前位 xor 后位）
4. i == 41: input[41] ^= input[0]（环回）
5. i == 42: input[42] ^= input[1]
6. SSE 比较：_mm_cmpeq_epi8(input, data1) AND _mm_cmpeq_epi8(input+1, data2)
7. _mm_movemask_epi8 == 0xFFFF → 全 1
8. 16 字节验证 = data1[0:16] = data2 位置
9. cipher = 60 字节 = data1 + data2 拼接
10. 爆破 1 字节逆推（'f' 开头）

## 关键 payload

```
input[i] ^= input[i+1-42*(i+1/42)]
```

## 经验教训

SSE 比较 128-bit 一次比较 16 字节，全 0xFFFF = 全部相等；input 自异或链 = 已知密文 + 知道异或关系 → 倒推明文只需 1 字节爆破（已知 flag 头 'f'）。
