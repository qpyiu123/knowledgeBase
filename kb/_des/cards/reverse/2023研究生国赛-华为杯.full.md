# 2023 研究生国赛华为杯 4 题 WP

> 赛事：研究生国赛华为杯 2023 | 方向：reverse | 难度：medium | 工具：Go、IDA

## 一句话总结

call $+5 混淆去 NOP + ChaCha 复用动调 + RC4+异或链 + Golang memequal + Unity Assembly-CSharp 日文假名密码。

## 攻击链

1. 打开 IDA 看不全代码 → call $+5 提示有混淆混淆 → 0x401560~0x4015B8 NOP 掉 → 重新 F5 看 init+enc 函数 → 动调拿 xor_array 数组 → cipher ^ xor_array = flag → 二叉树前序遍历断 val2/val3 反调试 → RC4 key=GoodLuck → 倒序异或链解 part3 → 还原 part4 索引 → Golang base64 密文 → memequal 断点 → 凯撒还原 flag → dnSpy 打开 Assembly-CSharp.dll → Win() 解 data1[i] ^ i → 加载成 DLL → Crypt.Decode 日文假名表

xor_array = [0xFF, 0x24, 0x3F, 0xDA, 0xBE, 0xA9, 0xB6, 0xF7, 0x12, 0x8F, 0x29, 0xD0, ...] ; cipher = [0x99, 0x48, 0x5E, 0xBD, 0xC5, 0x9B, 0x85, 0x96, ...] ; "REFTQ1RGe2hhc2FraS1wZHR6cHR6LXZ4bmZudX0=" ; "はりずめはばぐだすだちずそぬけびせやのぞはとらよはやこらのとほめせだむばのだのぢはやよぢせりにやのばぢ

## 经验教训

复杂的 init/enc 函数若只与输入无关则直接动调拿中间结果；Unity 题走 dnSpy 看 Assembly-CSharp.dll 是基本盘。
