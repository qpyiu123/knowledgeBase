## 一句话总结

腾讯游戏安全初赛 — R3 windbg 阻断 + R0 驱动加载阻断 + 自定义 base58 字符集 + XOR "sxx" + ACEDriverSDK::FilterSendMessage 通信。

## 攻击链

1. windbg 调试 R3 检测 → patch 模块+0x10D0 为 C3 (ret) 阻断
2. R0 驱动加载时直接结束程序 → patch 模块+0x1370 为 mov rax,1; ret
3. R3 校验: 输入以 "ACE_" 开头
4. 解密 base58 自定义字符集 "abcdefghijkmnopqrstuvwxyzABCDEFGHJKLMNPQRSTUVWXYZ1234567890!@+/" + 异或 key "sxx
5. base58_encrypt + 倒序 + '@' 前缀
6. XOR "sxx" 循环
7. ACEDriverSDK::Communicate(+96) 走 FilterSendMessage 发到驱动
8. 驱动侧校验密文

## 关键 payload

```
patch 0x10D0=C3 / patch 0x1370=mov rax,1;ret / base58 表+key "sxx" / ACEDriverSDK::Communicate
```

## 经验教训

R3+R0 双层反调试常见：模块+0x10D0 必为 ret；驱动加载前 sub_140001370 是阻断点；base58 自定义字符集在释放时是反推关键。
