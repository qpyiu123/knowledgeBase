# 2024 KCTF 大赛 - 第九题《第一次接触》设计思路及解析

> 赛事：KCTF大赛 2024 | 方向：reverse | 难度：hard

## 一句话总结

27 位序列号 + 三段校验 + 四皇后 + 反调试改乘数 + md5 爆破。

## 攻击链

1. 输入序列号必须 27 位（不是 24 也不是 30）→ 3 段各 9 位 → part1 头 8 位 = "hellocat" 不提第 9 位 → part2 "20211205" 反转 "50211202" * 3 = 150633606 但反调试把 3 改成 2 → 所以 part2 前面要再加 1 位 '0' → part3 "a3b1c4d29" 四皇后问题坐标 + 第 9 位 '9' 覆盖 g_serial3_verify 0x10000000 后的 0x39 → 唯一解 hellocatx202112050a3b1c4d29 → md5 校验 40d511825ecbc207eb6ef9a7b1c6e34b

## 关键 payload

```
hellocatx202112050a3b1c4d29 ; md5 = 40d511825ecbc207eb6ef9a7b1c6e34b ; g_serial3_verify = 0x10000039 ; 50211202 * 3 = 150633606 ; num3_531008 = 2（反调试改）
```

## 经验教训

序列号长度必须是 3 倍数 + 第 9 位覆盖隔壁变量的内存布局是 KCTF 老套路。
