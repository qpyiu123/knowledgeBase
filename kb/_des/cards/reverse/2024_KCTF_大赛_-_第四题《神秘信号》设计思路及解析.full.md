# 2024 KCTF 大赛 - 第四题《神秘信号》设计思路及解析

> 赛事：KCTF大赛 2024 | 方向：reverse | 难度：hard | 工具：Python

## 一句话总结

PyInstaller CrackMe 替换 base64 + XOR 0x55 + swap pair + hook input 偷数据。

## 攻击链

1. PyInstaller 解包 → main.py 在 _internal/ → import CrackMe 实际指向 base64 模块（importlib hook 把 CrackMe 名字替换成 base64）→ `CrackMe.main(data)` 实为 base64 编码 + XOR 0x55 + swap pair → hook input 拿到 CrackMe("KCTF") → convertinput("KCTF") = (ord(c) ^ 0x77) + 21 → crackme.main(convertinput("KCTF")) = "QQMlP7!!" → 写 ztokey 拼密钥 → 用 真实账号密码 得到验证码 → hook input 注入打印 → reverse 编码：rstrip ! → translate 字符表 → base64 decode → ^ 0x55 → 解得原始输入

## 关键 payload

```
convertinput(s) = bytes((ord(c) ^ 0x77) + 21 for c in s) ; CrackMe.main(KCTF) = "QQMlP7!!" ; ztokey(z) = "dZpK" + z[0:4] + "drsi" + z[4:8] + "B6cn" + z[8:12] + "drGY" + z[12:16] + z[16:] ; 字符表 ZQ+U7tSBEKVzyf5coCwb94Dd6raT0eLNin12Hp8mOxFuvMgIPlhRY3WjksqJAXG/
```

## 经验教训

PyInstaller CrackMe 在 hook 后模块名会被换，看 import sys.modules["CrackMe"] 才能看到真相。
