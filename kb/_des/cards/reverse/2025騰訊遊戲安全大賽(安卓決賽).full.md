# 2025 騰訊遊戲安全大賽 (安卓決賽)

> 赛事：腾讯游戏安全 2025 | 方向：reverse | 难度：hard | 工具：Python

## 一句话总结

腾讯游戏安全安卓决赛 — UE4 cheat 设备检测 (mtime 三相等 + 0x10 阈值) + mprotect/inotify/mincore 三重内存检测 + 函数 CRC32 完整性 + libUE4+0xAF75B08 注入 fake_memory + ImGui MainLoopStep 符号还原。

## 攻击链

1. 遍历 /dev/input/event* 拿触控事件 (返回 /dev/input/event2)
2. cheat 启动后新增 input47 (≥ 9 编号)
3. 遍历 /sys/devices/virtual/input/input9..255
4. cheat 设备特征 1: st_mtim == st_atim == st_ctim
5. cheat 设备特征 2: now.tv_sec <= st_mtim.tv_sec || (now-st_mtim) <= 0x10
6. cheat 设备特征 3: 计数器阈值 0x10
7. 函数完整性: CRC32(0x6711A54, 0x224) == 0x49d5c836 → 否则被 patch
8. mprotect 内存断点: hook mprotect 监控 RWX 切换
9. inotify 文件监视: hook open/write 检测 .so/.py 加载
10. mincore 物理内存检测: hook mincore, vec=1 表示在物理内存
11. 假内存 mmap: 在 libUE4+0xAF75B08 注入 fake_memory (PROT_READ|WRITE|EXEC) 末尾加 never_access_address
12. /dev/kmsg 日志监控: 监测内核日志
13. get_ThirdPerson 遍历拿 TP_ThirdPersonCharacter 对象
14. ImGui 还原 MainLoopStep 符号

## 关键 payload

```
cheat device 0x10 阈值 / CRC32(0x6711A54, 0x224)=0x49d5c836 / mprotect+inotify+mincore 三重检测 / libUE4+0xAF75B08 fake_memory / get_ThirdPerson + ImGui MainLoopStep
```

## 经验教训

安卓反作弊三重检测：cheat 设备 (mtime+阈值) + 函数完整性 (CRC32) + 内存页存在 (mincore)；fake_memory + never_access_address 是检测页错误的常见 trick。
