# 第八届浙江省大学生网络与信息安全竞赛技能赛初赛题解

## 一句话总结

第八届浙江省赛多题:Web反序列化POP链(User→Admin→FileReader)+RSA公因数e1/e2+密文二进制末尾判断+PWN格式化字符串负idx+long减key|逆XOR(round)+CSV-a1a60171273e74a6异或+数据脱敏(身份证+银行卡Luhn)

## 攻击链

1. Web反序列化: User.__toString→Admin.__call(getInfo)→FileReader.execute→file_get_contents(flag.php)|RSA公因数: 给出e1=65537, e2=10001, 同一n, 同一m加密, gmpy2.gcdext(e1,e2)求s,t组合plain|密文二进制转换: 读密文.txt列表每项末字符''p''或非判断0/1拼位→long_to_bytes|PWN-格式化字符串+任意地址写: sendlineafter("3.exit.","2") show(-15)泄libc_base=leak-0x1ed6a0+cmd("1") input libc_base+0xe3b01 gadget|逆round_unk_450000: XOR (key低16位) - 减 (key高16位)|CSV-base64+异或解码: 16字节key=''a1a60171273e74a6'' K[i+1&15]循环XOR|数据脱敏(身份证校验+Luhn银行卡): 严格模式校验

## 关键 payload

```
User->Admin->FileReader POP链|gmpy2.gcdext(e1,e2) → s, t = ...|for i in c: if i[-1]==112: p+=''0'' else: p+=''1''|show(-15) → libc_base=leak-0x1ed6a0|libc_base+0xe3b01|unk_450000[i]=(unk_450000[i]^(key&0xffff))-((key&0xffff0000)>>16)|de_encode(D, K=''a1a60171273e74a6'')
```

## 经验教训

1) PHP反序列化链跨3类调用:`User->role->getInfo`触发`Admin.__call('getInfo')`→`command->execute`触发`FileReader.execute`; 2) RSA e1/e2公因数攻击:同一m用不同e加密,gcd(e1,e2)=1则gmpy2.gcdext求s,t组合plain; 3) 密文二进制编码:每项末字符'p'(=0x70=112)表示0,其他表示1,逐位拼回; 4) 格式化字符串任意地址写:show(-15)负idx泄libc,再cmd("1")输入gadget地址; 5) C字符串逆算法:`data[i] = (data[i] ^ (key&0xffff)) - ((key&0xffff0000)>>16)`; 6) CSV字段加密:16字节key循环XOR+base64; 7) 数据脱敏验证:身份证校验码权重[7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2]+表[1,0,X,9,8,7,6,5,4,3,2]
