# 2023 红明谷杯 5 题 WP

> 赛事：红明谷杯 2023 | 方向：web | 难度：medium | 工具：PHP

## 一句话总结

CMS 后台任意文件读 + 主题包覆盖 + DNS XOR 带外 + DNA 密码替换。

## 攻击链

1. 登录 Dreamer CMS 后台 → 新建顶级栏目 → 封面模版写 ../../../../flag → 访问前台读 /flag → 复制主题包 default_v2 为 default_v3 → 改 themePath 为 ../../ → 上传启用 → 模板管理处可读任意文件 → ceye.io DNS 带外 cmd → XOR 解密 → DNA 三联密码替换还原 UUID flag → PNG 末尾 hex→BruteForce → PixelJihad 解密 → Decabit code 翻译 → 灰度图 LSB 按位交叉拼接
