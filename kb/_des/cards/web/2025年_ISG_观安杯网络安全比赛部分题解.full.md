# 2025 年 ISG 观安杯网络安全比赛部分题解（ezbank + babysec + blindpwn）

> 赛事：2025 ISG 观安杯 2025 | 方向：web | 难度：medium | 工具：GDB

## 一句话总结

2025 ISG 观安杯三题：ezbank 转账竞争条件 + babysec start.sh 密码 + blindpwn 整数溢出+write 泄露 canary 栈溢出。

## 攻击链

1. ezbank: 注册账户 → 不断向账户 8/9 转账竞争 → 余额够买 flag
2. babysec: 访问 start.sh 下载文件 → 文件里含密码 → 登录拿 flag
3. blindpwn: 整数溢出输入 -1 (0xFFFFFFFF 长度) → 栈溢出 → write 泄露栈
4. 17 字节后是 canary → 利用 write 把 canary 字节泄露
5. 第二次执行补 canary + 覆盖返回地址到 system
6. libc 2.35 偏移 system /bin/sh
7. 覆盖最后 1 字节 → 触发 debug 模式 → pwndbg 跟踪

## 关键 payload

```
整数溢出 -1 长度 → write 泄露 canary
```

## 经验教训

blindpwn 整数溢出 (scanf("%d", &len) 输 -1 = 0xFFFFFFFF) 是 pwn 高频套路；write(fd, buf, n) 自动把栈上 canary 当普通数据输出 → 二次执行补 canary。
