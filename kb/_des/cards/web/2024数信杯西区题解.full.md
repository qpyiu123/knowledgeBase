# 2024 数信杯西区题解（安全加固+应急响应+SQL 盲注+凯撒）

> 赛事：2024 数信杯西区 2024 | 方向：web | 难度：medium | 工具：Python

## 一句话总结

西区数信杯安全加固+应急：ssh/apache/redis 三件套 + Openfire 9090 改端口 + SQL 盲注二分 + 后门清理 + 凯撒密码+base64。

## 攻击链

1. 加固 1: ssh 关闭 PasswordAuthentication + 删 authorized_keys2 + service ssh restart
2. 加固 2: Apache ServerTokens Prod + Options -Indexes + Require all denied
3. 加固 3: redis requirepass 6b95fa87 + bind 127.0.0.1
4. flag1: netstat -ano 121.13.2.33:5432 外链
5. flag2: ps -aux 找 psql, /proc/PID/exe → /usr/bin/python3.6 反弹
6. flag3: openfire.xml 改 9090 → 12335
7. SQL 盲注: HTTP 响应长度 940/非 940 区分 ascii(substr(...))>N 二分
8. 后门: rm /etc/cron.d/safeline + deluser h4ck + chmod u-s zsh
9. 凯撒+base64: chr(ord(i)) ^ 0x18 → b64decode → 凯撒 shift=17
10. OpenCV: 高斯噪声 mean=0 sigma=3 还原 embedded.png

## 关键 payload

```
extract_data_from_logs: ascii_match + response_pattern + 二分 127 范围
```

## 经验教训

SQL 盲注即使有 WAF 也可走 HTTP 响应长度二分：920/940 长度差判 ascii(substr(...))>N，每次砍一半 128→64→32→1，log 批量 replay；Redis bind 0.0.0.0 + 无密码 = 裸奔公网。
