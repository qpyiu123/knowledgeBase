# 【春秋云境.com】首届仿真场景交流会，解锁挑战新思路

> 赛事：春秋云境 2022 网鼎杯决赛 2024 | 方向：web | 难度：medium

## 一句话总结

春秋云境仿真场景 2 个靶场复盘：XR Shop 4 flag 内网渗透 + 网鼎杯 2022 复盘 WordPress+永恒之蓝+CVE-2022-26923。

## 攻击链

1. Privilege 靶场: XR Shop 内网渗透 4 个 flag
2. 步骤 1: web 路径备份源码审计 → Jenkins 漏洞 → 拿下 Jenkins
3. 步骤 2: Jenkins 信息收集发现 Gitlab → 发现 Oracle 数据库信息
4. 步骤 3: 攻击 Oracle → XR-0923 主机 → 账号登录
5. 步骤 4: Windows 提权 → 域内 ACE 特权滥用 → 域控
6. 第二靶场 (网鼎杯 2022 决赛复盘): 4 个 flag
7. 步骤 1: 端口扫描 → WordPress 80 端口 → 后台弱口令 → getshell
8. 步骤 2: 内网信息收集 → 永恒之蓝主机 → metasploit 利用
9. 步骤 3: 提取账号密码 → 拿下域内机器 → 敏感 ACE
10. 步骤 4: CVE-2022-26923 域控提权

## 关键 payload

```
Jenkins+Gitlab+Oracle+XR-0923+域控 CVE-2022-26923
```

## 经验教训

内网渗透标准流程: 端口扫描 → Web 弱口令 → 内网信息收集 (Jenkins/Gitlab) → 数据库 (Oracle/MSSQL) → 提权 → 横向 → 域控；CVE-2022-26923 是 ADCS 域控提权。
