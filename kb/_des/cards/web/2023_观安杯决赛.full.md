# 2023 观安杯决赛

> 赛事：观安杯 2023 2023 | 方向：web | 难度：medium | 工具：Python

## 一句话总结

AWDP 实战：pma 弱口令+CVE-2018-12613 读 flag + ThinkPHP6 反序列化 RCE。

## 攻击链

1. web1 blog 框架，admin/pma 是 phpMyAdmin 后台
2. database.php 找到弱口令 ctf:ctf
3. SQL UPDATE ctf SET pass='' where user_id=1 改密
4. pma 弱口令登录 + CVE-2018-12613 任意文件读拿 flag
5. admin 弱口令（爆破出来）打其他队伍 flag
6. web2 ThinkPHP6 框架，public/sendtodatabase.php 命令注入点
7. app/encrypted.py 用 e=23 + 6 个不同 modulus 加密 flag（低指数广播）
8. /postdata 接口触发反序列化
9. think\Model + think\Request(filter=system, param=['whoami'])
10. think\session\Store(data=[$request, 'param'], serialize=['call_user_func'])
11. think\log\Channel(logger=$store) + think\route\Url(route=$channel)
12. think\model\Pivot($url) 整链触发 __destruct → __call → __toString
13. RCE 拿 /flag，绕过 encrypted_flag

## 关键 payload

```
database.php: MYSQL_USER=ctf, MYSQL_PASSWORD=ctf
```

## 经验教训

AWDP 关键是抢弱口令（ctf:ctf 通用）+ pma 后台任意文件读 + ThinkPHP6 反序列化链广存。
