# 看雪 2022 KCTF 春季赛 第十题 陷入轮回 Rust VM Pwn

> 赛事：KCTF春季赛 2022 | 方向：pwn | 难度：hard | 工具：Rust

## 一句话总结

Rust VM pwn：size_hint CVE 触发越界读写，Ubuntu 16 one_gadget 改 __libc_start_main_ret 拿 shell。

## 攻击链

1. 题目由 Rust 编写 VM pwn 变种，未删符号表
2. 漏洞来自 CVE-2021-2993 size_hint 错误实现
3. Rust 文档原话: size_hint() 不可信，错误实现不应导致内存安全违反
4. 程序读取指令模拟执行，指令集: vec / adj / cal / cmd / jmp / je / switch_stack / halt / print
5. StackVec<u64, 64> 模拟虚拟机栈（栈上分配，长度指示内容）
6. 越界读写漏洞通过 pop_back/push_back/pop_front/stack_ext 等指令触发
7. 改返回地址到 one_gadget
8. 仅 Ubuntu 16 可直接利用 one_gadget（其他需多个 gadget 组合）
9. exp 思路: vec int 填栈 + adj pop/push + switch_stack + cal stack_move + cal reg_to_stack
10. 通过 print 泄 rsp, libc_base, main 等地址
11. 二次利用: 改 __libc_start_main_ret 为 one_gadget

## 关键 payload

```
vec int 栈填充 + adj pop_back/push_back + switch_stack + one_gadget 改返回地址
```

## 经验教训

Rust 安全性 ≠ 绝对安全，第三方库 size_hint 错误实现会导致越界；带 debug 符号的 Rust 程序逆向更容易。
