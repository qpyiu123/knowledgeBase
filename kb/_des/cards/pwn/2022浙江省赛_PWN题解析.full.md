# 2022 浙江省赛 PWN 题解析（看雪 Nameless_a）

> 赛事：2022 浙江省赛 / 看雪 2022 | 方向：pwn | 难度：hard | 工具：ROP

## 一句话总结

堆题两套解：libc2.27 __free_hook；libc2.35 setcontext+ORW+fake link_map

## 攻击链

1. Proof-of-work: SHA256 4 字符爆破
2. fengshui 堆布局：0x418 + 0x410 + 0x410 + 0x420 + 0x420 chunk
3. free 0x420 触发 unsorted bin 残留指针 → show leak libcbase
4. tcache dup 写 __free_hook = system
5. edit '/bin/sh\x00' + delet(0) → system('/bin/sh')
6. glibc 2.35 升级版：setcontext+61 控制 rsp/rip + ORW (open/read/write) 读 flag
7. fake link_map 走 _dl_fini ROP 触发 _rtld_global 链

## 关键 payload

```
pd = p64(gold_key)+p64(free_hook) + p64(setcontext+61) + './flag\x00
```

## 经验教训

堆题要分清 libc 版本；2.27 直接 tcache dup + free_hook；2.35 走 setcontext+61 + 大数 ORW
