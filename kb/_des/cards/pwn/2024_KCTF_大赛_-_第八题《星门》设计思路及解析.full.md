# 2024 KCTF 大赛 - 第八题《星门》设计思路及解析

> 赛事：KCTF大赛 2024 | 方向：pwn | 难度：hard

## 一句话总结

seccomp 三 syscall + ptrace 注入 1 号进程 + 改 sleep 的 rip 跑 shellcode。

## 攻击链

1. 加载 seccomp → mmap 0x1000 rwx → 读 shellcode → 跳到 shellcode → ptrace ATTACH PID=1 (/bin/sh) → wait4 → PTRACE_GETREGS 取用户态寄存器 → 通过 r10/regs 算 libc 基址 → PTRACE_POKETEXT 写 sleep infinity 进程内的 libc 可执行段 → PTRACE_SETREGS 改 rip 跳到 shellcode → PTRACE_DETACH → 杀 PID=15 (sleep) 触发执行 → shellcode connect 外网 + open /home/sectest/flag + sendfile

## 关键 payload

```
seccomp_init(SCMP_ACT_KILL) + rule_add(ALLOW, ptrace/read/wait4) ; PTRACE_POKETEXT +0x77ae ; PTRACE_POKEDATA +0x29db4 ; flag{4297f44b13955235245b2497399d7a93}
```

## 经验教训

沙盒类 pwn 关键在 ptrace 注入到同 docker 内其他进程（通常有 sleep infinity）借其身份开 IO。
