## 一句话总结

2026 天府杯 pwn 0 解题目：libc-2.27 菜单题 add+show+0x400b7f/bea/ccd 子函数+result 全局标志 0/1，二次入口切换。

## 攻击链

1. libc-2.27 经典堆版本
2. setvbuf 关闭 stdout/stderr/stdin 缓冲
3. 菜单：mean() + input() 选 1/2/1337
4. add(0x400b7f) / show(0x400bea) / show(0x400ccd) 二次入口
5. result 全局变量 = 0 → 1337 显示一次后置 1
6. 下次进 1337 → result 返 0 直接退出
7. 0 解：题目难度大，48h 比赛 0 队伍提交

## 关键 payload

```
result=1 后 1337 失效，要重置触发两次入口
```
