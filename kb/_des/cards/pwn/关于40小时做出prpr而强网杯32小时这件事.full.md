# 关于40小时做出prpr而强网杯32小时这件事

> 赛事：N0wayBack 强网杯 / prpr 2024 | 方向：pwn | 难度：hard

## 一句话总结

N0wayBack 战队 40 小时做 prpr 强网杯 32 小时出题：自定义 VM 逃逸 + seccomp ORW + mprotect rop。

## 攻击链

1. N0wayBack 战队招新介绍 (Cain 叶师傅 cainyzb@qq.com)
2. prpr 强网杯 32 小时出题：自定义 VM (printf_chk opcode) + 二级 data 段
3. main 用 menu 循环 user_input pop_r/push_a_num/push_r/is_equal/if_false_jump/call/jmp
4. fun_60 二级 data 段：先 -2150 跳 vm_shellcode
5. 残留 register5=64 控 rip (fun_60 偏移)
6. 接收 %p libc+stack 泄露，%p heap 泄露
7. sl("-1003") sl("-1004") 分两次 32 位输出 64 位 heap
8. heap_base = (heap_h*0x100000000+heap_l) - 0x8d20
9. 改 register 指针指向 vm 栈底，栈迁移
10. leave_ret = 0x0562ec + libc_base
11. pop_rdi=0x2a3e5+libc_base, pop_rsi=0x2be51, pop_rdx_rbx=0x11f497, pop_rsp=0x35732
12. mprotect 7 (heap_base, 0x8000, RWX)
13. ORW syscall shellcode: open ./flag 0 + read fd 0x8000 + write 1
14. seccomp 沙箱: 只能用 open/read/write 不能 one_gadget

## 关键 payload

```
mprotect rop + orw shellcode: open(./flag)→read(0x8000)→write(1) + leave_ret 栈迁移
```

## 经验教训

自定义 VM 逃逸要先控制 vm 内部任意写 (改 register 指针/数据段) → 改主程序返回地址 → 栈迁移 → rop；seccomp 沙箱只能 open/read/write 时用 ORW shellcode 替代 one_gadget。
