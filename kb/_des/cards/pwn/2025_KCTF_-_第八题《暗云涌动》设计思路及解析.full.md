# 2025 KCTF 第八题《暗云涌动》设计思路及解析（自定义 VM+指针标记+整数溢出）

> 赛事：2025 KCTF 2025 | 方向：pwn | 难度：hard

## 一句话总结

2025 KCTF 第八题 暗云涌动：自定义 VM + 指针标记 + 整数溢出 bypass adjust_pointer → 任意地址读写 + IO 链劫持。星盟出题。

## 攻击链

1. VM 结构：pc/sp/stack(256 QWORD)/dmem(0x200000 1KB)/imem(0x1000 512 条 8B 指令)/regs(8 QWORD)
2. 指针标记：bit63=1 视为指针
3. adjust_pointer: 检查地址是否在 dmem[..+0xFF8] 或 stack[..+0x7F8] → 标记
4. 整数溢出：两非指针数加法高位溢出变指针，绕过 adjust_pointer 校验
5. 0x4000000000200000 + 0x4000000000000000 = 0x8000000000200000（溢出 bit63=1 → 标记为指针）
6. 任意地址读 + libc 偏移 + IO 链劫持
7. 堆地址爆破 4-bit

## 关键 payload

```
0x4000000000200000 + 0x4000000000000000 = 0x8000000000200000 (整数溢出→指针)
```

## 经验教训

自定义 VM PWN 必看 ALU 整数溢出是否破坏指针标记；堆地址爆破 4-bit（16 试 1 中）时考虑 async 并发。
