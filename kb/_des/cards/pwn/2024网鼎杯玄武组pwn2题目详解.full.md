# 2024 网鼎杯玄武组 pwn2 题目详解（SROP + read shellcode）

> 赛事：2024 网鼎杯 2024 | 方向：pwn | 难度：hard

## 一句话总结

网鼎杯玄武 pwn2：两次 read 触发二次栈溢出，用一连串通用 gadget 拼 SROP read 写 /bin/sh + execve，0x3B 经典 syscall 调用链。

## 攻击链

1. leave your name" 接收 0x28 字节 + p64(1) 写某标志位
2. Wanna return?" 接收 1 字节
3. once again?" 接收 0x100 字节触发栈溢出
4. 二次溢出覆盖返回地址到 rax=0x450277 通用 gadget
5. 通用 gadget 链：rax→0 / rdxrbx→0x10 / rsi→sh_addr / rdi→0 → syscall
6. read(0, sh_addr, 0x10) 写 /bin/sh\0
7. 二次 syscall：rax→0x3B / rdi→sh_addr / rsi→0 / rdx→0 → execve("/bin/sh", 0, 0)

## 关键 payload

```
rax=0x0000000000450277; syscall=0x41ac26; sh_addr=0x00000000004C5000
```

## 经验教训

大程序（看上去像真实服务）通用 gadget 链拼 SROP 是必备：rax=59 / rdi=sh_addr / rsi=0 / rdx=0 + syscall；read shellcode 后再 execve 是最简方案。
