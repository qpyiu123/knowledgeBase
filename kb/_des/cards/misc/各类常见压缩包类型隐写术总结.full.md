# 各类常见压缩包类型隐写术总结

> 赛事：压缩包隐写综合 2022 | 方向：misc | 难度：easy | 工具：010Editor

## 一句话总结

8 种压缩包隐写技巧：识别头/爆破/伪加密/CRC32 碰撞/已知明文/docx/注释/文件修复。

## 攻击链

1. 8 种压缩包隐写技巧总结
2. 1. 识别文件头: zip 504B0304 / rar4 526172211A0700 / rar5 526172211A070100
3. 2. 爆破: ARCHPR (日期/6 位纯数字/姓名首字母字典)
4. 3. 伪加密: 标志位奇数=加密, 偶数=未加密; 010editor 模板修
5. 4. CRC32 碰撞: 10 字节内 32-bit 校验值爆破 (th1s_hxb_secret = 0x292b7c58 + 0xee8d8709 + 0x5ca2e8e5)
6. 5. 已知明文攻击: Advanced Archive Password Recovery / bkcrack
7. 6. docx 是 zip: 改后缀解压找隐藏文件
8. 7. 注释信息: 压缩包注释位存数据
9. 8. 文件修复: 加文件头 504B0304 / 52617221

## 关键 payload

```
伪加密 + CRC32 碰撞 + 已知明文攻击 + docx=zip + 注释 + 修复
```

## 经验教训

zip 标志位奇偶控制伪加密; 10 字节内可 CRC32 碰撞; docx/jar/ipa 都是 zip; 已知明文攻击靠 bkcrack (3 个 32-bit key 12 字节差异)。
