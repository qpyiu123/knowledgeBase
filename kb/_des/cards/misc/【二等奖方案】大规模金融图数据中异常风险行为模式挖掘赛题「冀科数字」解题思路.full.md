# 金融图数据频繁子图挖掘 CCF BDCI 2022 二等奖方案

> 赛事：CCF-BDCI 2022 | 方向：misc | 难度：medium | 工具：C

## 一句话总结

金融交易图 3 阶频繁子图挖掘：C++ + mmap + OpenMP + 边属性标签化 + 排序分类 + 概率剪枝。

## 攻击链

1. 数据：账户 (account/card) + 边 A2A (account_to_account) + A2C (account_to_card)
2. 边字段：source_id, target_id, amt, strategy_name, buscode
3. 任务：3 阶频繁子图挖掘（链式 + 三角形环路），频繁度阈值 10000
4. 边属性合并编码 type_tag = source_name + target_name + amt + strategy_name + buscode
5. 标签化：用位操作整形拼接，O(1) 拼接 + O(log) 排序
6. 两层排序：type_tag + source_id，按 type_tag 类别区间标识建字典
7. 按 source_name + target_name 二次区间标识建索引字典
8. 决策树遍历：首边 → 末边（双层循环按边属性类别）→ 中间边（按衔接点 name 索引）
9. 概率剪枝：估算子图频繁度 E = n_i · n_j · (account_count / total)^3
10. 当 E < 阈值时跳过精确比对
11. 衔接点匹配二分查找（按 source_id 已排序）
12. 优化：C++ mmap 数据读取 + OpenMP 并行 + 概率剪枝

## 关键 payload

```
3 阶子图，频繁度 ≥ 10000，链式 + 三角形环路
```

## 经验教训

频繁子图挖掘的核心是减少比较次数，边属性标签化 + 排序 + 概率剪枝 + 并行是工业级 4 把刀。
