# 【WP】2022数字中国创新大赛车联网安全赛初赛

> 赛事：数字中国 2022 | 方向：misc | 难度：medium

## 一句话总结

2022 数字中国车联网初赛 6 题 WP，CANopen 协议 SDO 读对象解析 + 仲裁 ID 表查询。

## 攻击链

1. 1. pcap 字符串提取 strings maybeEasy.pcapng > maybeEasy.txt 找 CANopen 协议 /2. SDO 读对象 0x1000 设备类型 + 0x1008 设备名 + 0x1009 硬件版本 + 0x100A 软件版本（CS=40 主→43/41 从回应）/3. 解析 hex 为 ASCII 得 CANopenDemoLinux-9f1b + f957da98 + b0459595fd93/4. CANopenDemoLinux 专属仲裁 ID 表 0x2120 子 ID 表

## 关键 payload

```
设备类型 41f7  设备名 CANopenDemoLinux-9f1b  硬件版本 f957da98  软件版本 b0459595fd93
```

## 经验教训

CANopen 协议常用对象：0x1000 设备类型/0x1008 设备名/0x1009 硬件版本/0x100A 软件版本；SDO 读命令 CS=40 + 索引 + 子索引；从响应 CS=43（多字节）或 41（字符串）；CANopenDemoLinux 是开源 CANopen 协议栈。
