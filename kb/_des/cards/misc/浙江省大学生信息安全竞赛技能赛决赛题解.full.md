# 浙江省大学生信息安全竞赛技能赛决赛题解

> 赛事：浙江省信安赛 2025 | 方向：misc | 难度：medium

## 一句话总结

浙江省信安赛 6 题：XOR + JNI strcmp + RSA p+q-pq + 数据清洗 + 滑动窗口 + 鸿蒙 RC4 矩阵密码。

## 攻击链

1. Crypto 1: CIPHER[i] ^ (i & 0xff) 异或解密
2. Android JNI: strcmp 比对 "NBWX633YNJLU2QSILZBUKSDTJVBFQRLTJVBEQ42YJFPVQ42FL5ZUKQSYJFPESX2YIVBEWUI=
3. RSA: sum_pq + diff_pq 求 p, q，d = pow(e, -1, phi)，m = pow(c, d, n)
4. 数据清洗: 18 位身份证（含校验码 [7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2] 加权 + check_table） + 11 位手机号 (1 开头全数字) + 中文姓名 [\u3000-\u9fff]{2,4} + 性别 (17 位奇男偶女) + 出生日期 (身份证 vs 表中) + 注册/登录时间
5. 滑动窗口: 1 小时窗口 + freq_bad (单用户订单>10) + card_bad (卡号复用多用户)
6. 鸿蒙 HarmonyOS: arc4Key = "HarMonyOS_S3cur3_K3y!2025" + 上三角 MatrixCrypto [[1,2,3],[0,1,4],[0,0,1]] + RC4 + CustomBase64
7. 矩阵解密: M^(-1) * vector(Integers(256), v) 还原明文

## 关键 payload

```
CIPHER[i] ^ (i & 0xff) + RSA p = (sum+diff)/2 + MatrixCrypto 上三角逆 + RC4
```

## 经验教训

多技能融合赛，XOR/RSA/数据清洗/滑动窗口/矩阵密码各占一题；身份证校验码权重 [7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2] 必背。
