# 赛前热身第3期|「第十六届全国大学生信息安全竞赛」安全可信赛题

> 赛事：第十六届全国大学生信息安全竞赛 安全可信赛题 2023 | 方向：misc | 难度：medium

## 一句话总结

第十六届全国大学生信息安全竞赛安全可信赛题,基于cube-1.3+cube-tcm可信计算模拟器,涵盖可信报告两阶段流程+PCR寄存器设置+策略组合验证+SM2密码学。

## 攻击链

1. 镜像环境:cube-1.3(通用可信软件基框架)+gm_sm2_master(开源SM2库)+cube-tcm(可信密码模块模拟器+驱动)+cube_tcmplugin(模块封装)+tcmenv_exec(测试环境)
2. 运行tcm_quote.sh启动可信报告机制
3. 五个角色:user/term/server/crypt_user/crypt_hub
4. 阶段1:user发可信报告命令→term拦截转到server→server拦截转给crypt_user→key_manage生成防重放随机数→返回term
5. 阶段2:term交给key_event添加节点和用户信息(MESSAGE,INSTANCE_INFO)→拦截到crypt_user→key_manage配可信报告模板(TCM_PIK_DESC,PCRQUOTE)→pcr_multirw读pcr值→quote_report生成报告
6. 报告回term→转server→crypt_hub的key_event接收→key_manage存储报告→quote_report验证→删报告内容→key_manage解析报告内容→结论返回user
7. 关键:pcr_set.sh清零pcr,调用pcr_set实例向14号pcr寄存器写入数据(策略摘要值)
8. policy_list中列出某几项数据的摘要值
9. 修改instance/node/pcr_set/policy_write.msg中的return_value(14号寄存器+策略摘要名)
10. 验证逻辑:遍历内存库所有摘要值,确定pcr由哪些策略组合,policy_choice->return_value输出
11. 故意留下bug:完整性报告验证过程有bug,感兴趣的同学可研究

## 关键 payload

```
TCM_PIK_DESC + PCRQUOTE + 策略组合
```

## 经验教训

可信计算(TCM/TPM)是新兴CTF方向,cube-1.3是国内主流可信计算模拟器框架;可信报告机制(PCR_QUOTE)是核心安全机制;策略组合验证需要遍历内存库+解析return_value。
