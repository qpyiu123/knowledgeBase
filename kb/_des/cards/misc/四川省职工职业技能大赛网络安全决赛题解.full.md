## 一句话总结

四川省职工决赛 6 题: phar 反序列化 + 楞伽经 AES + 自定义 Sbox AES + tcache one_gadget + 流量 csv 统计。

## 攻击链

1. 题1 phar.php: class A __destruct + class B __invoke + system($cmd)
2. $a->a = new B(); $b->cmd = "cat /flag
3. Phar::setMetadata($a) + .phar 打包
4. upload.php 把 .phar 改 .png 上传 (uniqid().png)
5. file_get_contents($_GET['file']) + phar:// wrapper 触发
6. 题2 DASCTF 楞伽经: ruShiWoWen 表 256 字符, index ^ 64 得字节
7. KEY = DASCTF@Key@^_^@Encode!!Buddha!!!
8. IV = IV|DASCTF|OvO|IV
9. AES-CBC 解密
10. 题3 自定义 AES: 256 字节 Sbox 自实现, Rcon 标准
11. key = "Hi Android!0oO00" + table 置换 [0x0A,0x02,0x01,0x0D,...]
12. 32 字节密文解密
13. 题4 pwn_1 libc 2.27: add 9 个 + free 8 个 + show 泄 heap/libc
14. edit(3, p64(__free_hook)) + add(one_gadget 0x4f302) + free(0) → shell
15. 题5 流量分析: event_type_count 统计 + top_source_ip 提取
16. 题6 流量分析: IP 整数化 + 连接 (src+sport+dst+dport) + packet_size 累加

## 关键 payload

```
phar 楞伽经 + 自定义 AES Sbox + tcache one_gadget 0x4f302 + 流量分析
```

## 经验教训

phar:// wrapper 是 PHP 文件上传配合反序列化的金钥匙; 楞伽经类题是自造字符表 (256 字符) 索引加密; tcache __free_hook + one_gadget 0x4f302 是 glibc 2.27 标准 UAF 利用。
