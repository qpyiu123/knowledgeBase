# 鹏程杯 (我当上了全栈菜鸡？) YunSee Writeup

> 赛事：鹏程杯 2025 | 方向：misc | 难度：medium | 工具：Django、netcat

## 一句话总结

鹏程杯全栈：Cookie 改 admin 竞争上传 + Django cache pickle RCE + SM4 改 MASK key schedule + MQTT 注入。

## 攻击链

1. web-ezphp: 弱口令 + cookie admin 改 0→1 + 条件竞争 + 上传 race.php (printf system) + 200 线程 while 循环
2. pcb5-ezDjango: Django 文件型缓存 pickle+zlib 序列化到 /tmp/django_cache/*.djcache
3. 任意复制写 .cache 文件 + pickle RCE: cos system S''cmd'' o.
4. 触发键: pwn:e4a25f7b... / :1:pwn:063ac062... / flag:327a6c43... / env:ff035a1d... / db:d77d5e50...
5. pcb5-meddddgo: SM4 ECB + MASK key schedule
6. MASK = [0xA5A5A5A5, 0x3C3C3C3C, 0x5A5A5A5A, 0xC3C3C3C3]
7. K[i] = MK[i] ^ FK[i] ^ MASK[i]
8. 派生 key: key[i] = ROL1(seed[(5i+3)&0xF], 1) ^ (11i) ^ 0xA5
9. 3 轮混淆: key[j] ^= (17*r + key[(j+1)&0xF] + key[(j+5)&0xF]) & 0xFF
10. flag = flag{12d8b17b8ae52636a1211299451f9f6c}
11. 30 轮 TEA-like 变种 (delta=0x23251156, v += (v<<5)^sum^(v>>4)) + 6 组 32-bit
12. MQTT 协议 nc 注入: set_vin 通过校验 + 窗口期覆盖 arg = 合法前缀;cat /home/ctf/flag #

## 关键 payload

```
cookie 改 admin 0→1 + 竞争条件上传 race.php + Django cache pickle RCE + SM4 ECB 改 MASK + 30 轮 TEA-like
```

## 经验教训

Django 文件型缓存 pickle 反序列化是经典 RCE；MQTT 协议窗口期命令注入需时序控制。
