# 吾爱破解 2026 春节所有题 WP

> 赛事：吾爱破解 2026 春节解题 2026 | 方向：misc | 难度：hard

## 一句话总结

吾爱破解 2026 春节: Native verifyAndDecrypt 反馈链 + WASM 0x2026 次 SHA-256 + Frida hook 64 字节比较点。

## 攻击链

1. Native verifyAndDecrypt: plain[i] = cipher[i] ^ keystream[i] ^ feedback[i]
2. 第一块 feedback 来自 IV, 之后每块 = 当前密文块
3. Native 函数偏移: startSessionBytes 0x247b0 / checkRhythm 0x24da8 / updateExp 0x24ea4
4. decryptFrames 0x2541c / verifyAndDecrypt 0x257dc / setDebugBypass 0x25c90
5. Native 验签成功判定: h1.a.S((byte[]) obj) == null
6. WASM genFlag(uid, voice) + checkCode 0x2026 次 SHA-256 比较 currentHash
7. 14 字节 key: 00 01 01 01 01 01 01 00 01 00 01 00 05 02
8. 映射表: abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789?!
9. hook crypto.getRandomValues 截 17 字节随机
10. 64 字节 flag hex → sub_1400CF090 转换 + sub_1400CF270 长度 0x40
11. sub_1400CF910 核心校验 (反调试) + sub_1400D3B20 64 字节最终比较
12. Frida hook 0xD3B20 onEnter 截 lastY + 反调试清零
13. 复核链路: ctf_request=口令 (非 access_token) + audit_log_id 用被拒访问完整编号

## 关键 payload

```
verifyAndDecrypt feedback XOR + WASM 0x2026 SHA-256 + Frida hook 0xD3B20 64 字节
```

## 经验教训

Native 验签成功判定要找 h1.a.S((byte[]) obj) == null 这种"成功条件"；WASM crypto.getRandomValues 必 hook 拿 17 字节随机种子；Frida hook 0xD3B20 onEnter 拿 64 字节目标值是 Windows RE 标准姿势。
