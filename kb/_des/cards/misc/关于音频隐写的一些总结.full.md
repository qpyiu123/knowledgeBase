# 关于音频隐写的一些总结

> 赛事：音频隐写综合 2023 | 方向：misc | 难度：easy

## 一句话总结

音频隐写 6 大工具 + 7 种题型总结：WAV 频谱/SSTV/DeepSound/MP3stego/DTMF/MIDI/原始数据。

## 攻击链

1. 工具集: Audacity/Adobe Audition(au)/SilentEye/DeepSound/SSTV/mp3stego
2. WAV 文件头: 57415645
3. Audacity 频谱图: 上下峰二进制 + 倒序反相慢速降噪
4. SSTV (慢扫描电视): Robot36 (Android) / MMSSTV (PC) 把图片藏到音频
5. DeepSound: 密码音频隐写, john 爆破密码
6. MP3stego: cmd Decode.exe -X <mp3> -P <pass>
7. 拨号隐写 (DTMF): https://gitcode.net/mirrors/ribt/dtmf-decoder
8. MIDI 隐写: 4D546864 头, 改音乐通道 2→3 找隐藏 QR
9. 信号分析: HackRF / GPS / PT2242 (4bit 同步+20bit 地址+4bit 功能+1bit 停止)
10. 原始数据: 后缀 .s8 等奇怪后缀用 Import Raw 选采样率/尾端/编码

## 关键 payload

```
sstv+robot36 + mp3stego + john deepsound + dtmf-decoder
```

## 经验教训

音频题先听一遍无信息 → Audacity 频谱图 → 上下峰二进制/倒序反相/慢速降噪；MIDI 4D546864 头可改通道数；HackRF/原始数据后缀 .s8 需 Import Raw。
