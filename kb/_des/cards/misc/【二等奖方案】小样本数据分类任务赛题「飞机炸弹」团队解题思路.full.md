# CCF BDCI 2022 二等奖 - 小样本专利分类 飞机炸弹团队

> 赛事：CCF BDCI 2022 (第十届CCF大数据与计算智能大赛) 2022 | 方向：misc | 难度：hard

## 一句话总结

哈工大(深圳)研究生用RAKE+SimCSE+MemoryBank+R-Drop在小样本专利分类上A榜0.6371/B榜0.6023。

## 攻击链

1. RAKE抽取关键短语 → 北大专利数据集MLM+SimCSE领域预训练 → 4个预训练模型(roberta-wwm/mengzi/nezha/bert-for-patents) → 5个Dropout+共享分类头 → MemoryBank对比Loss → R-Drop KL损失 → 5折融合 → 伪标签迭代+标签平滑

## 关键 payload

```
RAKE关键词 + MLM+SimCSE预训练 + MemoryBank + R-Drop + Mixup + 5折融合
```

## 经验教训

长文本小样本场景先用RAKE降学习难度;MemoryBank+BCELoss+对比学习防过拟合;R-Drop利用Dropout机制构造正例;SimCSE同一句子两次前向作为正样本对;中翻英+bert-for-patents在英文域效果更好;Mixup在batch内折半翻转构造增强。
