# 无痕驱动的检测与分析 重映射驱动靶场构造 扫描与特征剥离

> 赛事：安全研究 2024 | 方向：misc | 难度：hard

## 一句话总结

Windows 内核"无痕"驱动深度分析，PE 重映射 + CFG 绕 + PoolBigPageTable 检测 + PTE 全扫描。

## 攻击链

1. 1. 重映射方式加载驱动：解密 Shellcode + 解析 SizeOfImage 内核态分配内存 + 手动拉伸 PE + 修复 Reloc (IMAGE_REL_BASED_DIR64) + 修复 IAT + 刷新 SecurityCookie + 抹除 PE 头/2. 劫持系统调用指针：NtQuerySystemInformation(103) 间接 call 到 sub_140A0AE40 + guard_dispatch_icall + InterlockedCompareExchangePointer 替换回调 + DRV_COMM_MAGIC=0x789456123/3. 检测 PoolBigPageTable 内存痕迹：MmAllocateContiguousMemory → MiAllocateContiguousMemory → PoolBigPageTable[slot].Va + .Size/4. 扫描内核可执行内存：PTE 4 级页表遍历 4KB 页面 + LargePage 1GB/2MB

## 关键 payload

```
DRV_COMM_MAGIC = 0x789456123  PoolBigPageTable 结构  PTE 4 级页表遍历
```

## 经验教训

PE 重映射需修复 Reloc/IAT/SecurityCookie；劫持 NtQuerySystemInformation 间接 call 走 CFG guard_dispatch_icall；PoolBigPageTable 记录大块连续内存分配；PTE 4 级页表遍历扫描可执行页是反 rootkit 利器。
