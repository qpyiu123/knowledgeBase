# 2024 羊城杯数据安全 AK 篇（CSV 数据清洗 + 身份证校验）

> 赛事：2024 羊城杯粤港澳大湾区网络安全大赛 2024 | 方向：misc | 难度：easy | 工具：tshark

## 一句话总结

数据安全 AK 流水线：tshark 抽 POST→正则按字段分类→身份证 GB 11643 校验+性别位+手机号段白名单→写 garbage_data.csv。

## 攻击链

1. tshark -Y http.request.method==POST -T fields -e json.value.string 抽 POST body
2. 8 字段正则分类（手机/身份证/出生日期/性别/密码/姓名/编号/用户名）
3. validate_id_number: 加权 [7,9,10,5,8,4,2] % 11 + check_codes 10X98765432
4. validate_sex_idcard: 身份证倒数第 2 位奇偶 vs 男/女
5. validate_phone: 53 段手机号前缀白名单
6. error.log: re.search ''username=.*'' 取账户行 + ''\x81\xe4\xb8\xba''/''为'' 关键字行拼 password
7. parser2list: 用户名/姓名首末保留+中间 * 化 + 身份证 6+4+8 * 化 + 手机号 3+4+4
8. hashlib.md5(password.encode()).hexdigest() 加密字段

## 关键 payload

```
if int(idcard[-2]) % 2 == 0: idcard_sex = "女" else: idcard_sex = "男
```

## 经验教训

身份证 18 位校验码是 GB 11643 强约束（加权 [7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2] 再 % 11 对 '10X98765432'），手机号段归属地可作反欺诈证据；error.log 解析要按业务中文关键字定位上下文（"为" = 输入密码提示）。
