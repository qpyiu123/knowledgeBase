# 2024 能源网络安全大赛预赛【金盾检测】

> 赛事：能源网络安全大赛 2024 | 方向：misc | 难度：easy | 工具：Java、tshark

## 一句话总结

工控 GOOSE/FINS/Modbus 流量 + 小 RSA + base64 隐写 + ysoserial CC2。

## 攻击链

1. 1. GOOSE 协议 4 个 item 中第 4 个 < 128 转 ASCII → 再 base64 → 再 base32 → flag / 2. DCS http 4343 帧存 HTML → 找双网卡 IP / 3. Modbus 追踪流得 flag UUID / 4. FINS 协议响应数据按规范构造 / 5. 图片改高得 zip 密码 → base64 隐写提取 / 6. RSA 小 n → yafu 分解 → 解密 / 7. Java ysoserial CommonsCollections2 反序列化打 4.4

## 关键 payload

```
tshark.exe -r data.pcapng -e "goose.integer" -T fields ; int(s)<128 → chr() ; FINS 响应 = 46494e53000000160000000200000000c000020064004001020000 ; base64stego = bin(table.index(i))[2:].rjust(8,'0') + '='-encoded hidebit
```
