# 2022 智能网联汽车漏洞挖掘赛 WP by 1024SEC

> 赛事：2022 智能网联汽车漏洞挖掘赛 2022 | 方向：misc | 难度：medium | 工具：Python、tshark

## 一句话总结

2022 智能网联汽车：UART 帧格式 + USB 键盘流量 + Hill 密码 ngram

## 攻击链

1. Q1 UART: 附件是 Saleae 逻辑分析仪导出, 还原 8-N-1 帧格式, 解析串口数据
2. Q2 USB HID: tshark -r usb.pcap -T fields -e usb.capdata 提取 8 字节键盘数据
3. WangYihang UsbKeyboardHacker.py 解析 04-2b 16 进制键码 → normalKeys / shiftKeys 映射
4. 每个键 8 字节: 修饰键 + 保留 + 键码, 第 3 字节非 0 即按键
5. Q3 Hill cipher: ciphertext 走 ngram quadgrams.txt 评分 → 评分函数 + Alphabet'', ''Alphabet_base, 优化 N=100 选最佳置换
6. Q4 智能车 CAN/CAN-FD: 抓包 → 找异常帧 → 找 flag ECU 地址

## 关键 payload

```
tshark -r usb.pcap -T fields -e usb.capdata 'usb.data_len == 8' > usb.txt
```

## 经验教训

智能网联汽车安全 = UART + USB + CAN-bus + OTA；UsbKeyboardHacker 是经典工具
