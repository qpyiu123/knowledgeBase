# 一次银狐样本分析

> 赛事：安全研究 2026 | 方向：misc | 难度：medium

## 一句话总结

银狐木马样本分析，PEB 遍历模块 + API Hash 还原 + ShellCode Loader 动态调试 + C2 提取。

## 攻击链

1. 1. PEB->InMemoryOrderModuleList 遍历双向链表 找 BaseDllName /2. 比较 DLL 名找基址 /3. API Hash 算法还原 (ROR13 常见) /4. 解析 DLL 导出表 哈希 API 名匹配 /5. 动态调试：自实现 Loader 加载 ShellCode /6. 提取 C2: 156.234.119.138:443 / syumineyt.top:80 / syumingeyt.top:8080

## 关键 payload

```
PEB InMemoryOrderModuleList  syumineyt.top  syumingeyt.top  API Hash 还原
```

## 经验教训

银狐木马典型用 PEB 隐藏 API 调用；API Hash = 常见 ROR13 算法；动态调试需自实现 Loader；C2 通信地址 t1/t2/t3 区分协议。
