# 斟茶王者常规赛 数据研判专项

> 赛事：斟茶王者 2024 | 方向：misc | 难度：easy | 工具：Python

## 一句话总结

斟茶王者数据研判：grep access_key_id + admin_log IP 聚合 + user_log 登录 + balance_log 下级 + order 范围 + pymysql 团队销售。

## 攻击链

1. 1. grep 搜 access_key_id: `grep -rn ''/www/wwwroot/testing-2th.ns'' -e ''access_key_id
2. 2. admin_log 按 IP 聚合:
3. SELECT ip, COUNT(*) as count FROM admin_log GROUP BY ip ORDER BY count DESC;
4. 3. user_log login_ip 聚合:
5. SELECT login_ip, COUNT(*) as count FROM user_log GROUP BY login_ip ORDER BY count DESC;
6. 4. balance_log 627 下级 sum:
7. SELECT SUM(amount) FROM hdk.balance_log WHERE uid='627' AND desc LIKE '%下级%';
8. 5. order 时间范围 + goods_id 范围:
9. SELECT * FROM order WHERE order_time BETWEEN 1696089600 AND 1698768000 AND goods_id IN (4,5,6,7,8,9,10,11);
10. 6. pymysql 递归团队销售额:
11. team_members = {pid: [uid, ...]} 建图
12. count_sales(uid) 递归 SUM(pay_amount)

## 关键 payload

```
grep -rn + admin_log + user_log + balance_log + order 1696089600-1698768000 + pymysql 递归
```
