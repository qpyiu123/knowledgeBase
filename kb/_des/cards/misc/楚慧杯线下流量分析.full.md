# 楚慧杯线下流量分析

> 赛事：楚慧杯 2026 | 方向：misc | 难度：easy

## 一句话总结

楚慧杯流量分析：识别冰蝎3 behind.php + 蚁剑 .shE11.php + AES 解密 + base64 二层解码找 key 和 flag。

## 攻击链

1. 过滤 HTTP 流量找到 .shE11.php（蚁剑特征）和 behind.php（冰蝎 3.x 特征）
2. 第一条 behind.php 流量找到冰蝎马绝对路径
3. 30 流解密：去掉开头两位 base64 编码，base64 解码蚁剑命令
4. 30 流中找到冰蝎马的绝对路径 + 16 进制编码字符（疑似 key）
5. 39 流解密冰蝎响应体：冰蝎 AES 加密 + 内层 base64 编码
6. JSON parse 解密后的数据：name/size/lastModified/perm/type 字段均 base64
7. base64 解码 ls 命令结果，找到 /tmp 扫描器
8. 找到黑客上传至 /tmp 目录的扫描器

## 关键 payload

```
16 进制 key 字符串 + 冰蝎 AES 解密 + base64 二层解码
```

## 经验教训

冰蝎3 与蚁剑的特征 URL 识别是流量取证基础；AES 加密 + base64 双层编码是常见 WebShell 通信模式。
