# CTF 知识库

离线查询编程文档、CTF 方法、题型和配套代码。先看关键词结果，按需补充语义检索；深度搜索、直接模式和翻译的结果在侧栏查看。

## 开始使用

在 Windows 双击 [启动.cmd](启动.cmd)，浏览器会打开 [本地查询页](http://127.0.0.1:8765/)。打开应用不加载生成模型。第一次使用解释时按需加载，也可在设置里改为仅手动启动。使用项目内的独立 Python，无需另装系统 Python。

关掉浏览器后服务仍在运行。用完后，关掉启动时留下的命令窗口，或在窗口里按 Enter，即可停止本次启动的查询和解释服务。文章和任务结果侧栏可拖动左边缘调整宽度。

在项目目录打开终端，也可以运行：

```powershell
.\启动.cmd -Status                 # 查看状态
.\启动.cmd -Stop -NoModel          # 停止查询服务
.\启动.cmd -CheckEnvironment       # 检查 Python 和依赖
.\启动.cmd -Start                  # 启动查询界面
.\启动.cmd -Console -ChatModel qwen35-4b  # 保留窗口，本次选用 4B
```

设置页可启动、停止和切换解释模型。查函数名、报错或题面特征时，可以直接粘贴原文。
