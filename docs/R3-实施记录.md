### 已实现

- R3.1 已提交 `9b67c36`。本批复制两份完整 Qwen3.5 GGUF 与 52 个 Vulkan 运行文件，原件、旧 Qwen3 和 `.part` 均保留。文件清单及原下载来源见 `docs/data/llama-resources.json`；模型与运行库不提交 Git。
- `config.toml` 默认 `llama_server` / `qwen35-9b`，8192 上下文、6 线程、99 层 GPU 卸载。`start.ps1 -ChatModel qwen35-4b` 临时选择 4B，退出后恢复原环境；`KB_CHAT_MODEL` 可显式覆盖命令行使用的模型，`-CpuOnly` 选择 CPU。
- 服务只监听 `127.0.0.1:8766`，单生成槽，使用 GGUF 自带模板，默认关闭思考输出。跨站来源限本机，关闭原生网页与 agent 工具。网页和命令行共用 `LlamaServerBackend`；服务所载模型与选择不一致时提示重启，不混用模型。
- 独立启动、状态和文件复用工具分别为 `tools/llama_runtime.py`、`tools/prepare_llama_resources.py`。准备工具不覆盖大小不同的已有文件，不接收未完整的模型。
- 网页保留 `tok / err / done`；生成器关闭时关闭上游连接。模型流为空、格式有误、提前断开或服务不可用均有错误提示。`llm.backend=none` 和 `-NoModel` 均可关闭解释。
- 网页按查询词选相关小节，命令行同时利用已命中的小节；保留小节内代码，不把代码里的 `#` 注释当标题。长段取命中词附近片段并标记余文位置，遵守原字符预算；命令行也拒绝读取库外路径。
