# CTF 知识库：离线包使用说明

适用 Windows x64。复制整个目录，保留子目录。无需安装 Python、Node.js 或 Git。

## 启动和停止

双击 `启动.cmd`，浏览器会打开 [本地查询页](http://127.0.0.1:8765/)。双击只查资料，不加载生成模型。可直接输入函数名、报错或题面特征，需要时再打开语义补充。

关掉浏览器后，命令窗口会继续保留。关闭该窗口，或在窗口里按 Enter，停止本次启动的查询和解释服务。

在包目录打开终端，可运行：

```powershell
.\启动.cmd -Status
.\启动.cmd -Stop -NoModel
.\启动.cmd -CheckEnvironment
```

## 模型解释

含模型的包在首次使用解释时才加载权重。双模型包可在设置选择 9B 或 4B；没有可用 Vulkan 时改用 CPU。保存设置后可以在同一页面启动、停止或重启模型。模型清单在 `release-manifest.json`。

## 资料更新

变更资料后先关服务，再运行 `.\启动.cmd -Reindex`。语义查询依赖随包的 BGE ONNX 与匹配的索引。个人题目记录在 `work/`，新包不带旧记录。

第三方来源和许可见 `licenses/离线包第三方来源.md`。
