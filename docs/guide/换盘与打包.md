# 换盘与打包

当前处于开发阶段，需要分发时再生成离线目录。从项目根目录运行：

```powershell
.\runtime\python-portable\python.exe -X utf8 tools\pack_release.py --models both
```

可选择 `--models both`、`9b`、`4b` 或 `none`（仅查询），也可用 `--destination <新目录>` 指定输出。默认输出在 `release/`，不会覆盖已有目标目录。

复制整个离线目录到 Windows x64 的可写位置。9B 权重单文件超过 4 GB，移动盘使用 NTFS 或 exFAT。进入新目录，双击 `启动.cmd`，或用 `.\启动.cmd -CheckEnvironment` 检查环境。离线包带独立 Python，无需另装 Node.js 或 Git。

模型放在 `models/`，Vulkan 运行库在 `runtime/`。复制到另一盘符时保留目录结构；只换路径不需要重建索引。包内步骤见 [离线包使用说明](离线包使用说明.md)。
