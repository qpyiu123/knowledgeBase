# 使用与查询

在 Windows 双击 `启动.cmd` 后，在 [本地查询页](http://127.0.0.1:8765/)输入函数名、报错、代码符号或题面特征。双击只启动查询，命中小节可打开原文和配套代码。

- 词不确定时，打开“语义补充”；精确查函数和异常时，先用关键词。
- 有题目条件时，打开“显示条件关联”，核对适用、待查和不适用的前提。
- 选好题目工作区后可使用“参考当前卡点”。详细用法见 [遇到卡点怎么查](遇到卡点怎么查.md)。

需要解释时，先停止仅查询服务，再启动带模型的服务：

```powershell
.\启动.cmd -Stop -NoModel
.\启动.cmd -Start
# 可选：改用 4B，或在无 Vulkan 时加 -CpuOnly
.\启动.cmd -ChatModel qwen35-4b
```

默认解释模型由 `config.toml` 的 `[llama_server].model` 决定。切换模型前先运行 `.\启动.cmd -Stop`。服务状态可用 `.\启动.cmd -Status` 查看，日志在 `logs/`。

启动入口只为本次调用指定 PowerShell 执行策略，不修改系统或用户设置。
