# 使用与查询

在 Windows 双击 `启动.cmd` 后，在 [本地查询页](http://127.0.0.1:8765/)输入函数名、报错、代码符号或题面特征。双击不加载生成模型，命中小节可打开原文和配套代码。

文章和任务结果侧栏可拖动左边缘调整宽度。也可以用 Tab 选中边缘，再按左右方向键。关掉浏览器后，关闭启动时的命令窗口或在窗口里按 Enter，即可停止本次服务。

- 查函数时从左侧进入“语言文档”，输入语言和完整函数名，例如 Python base64.b64decode 或 PHP str_replace。结果直接给中文说明，阅读按钮打开对应小节；不需要启动解释或语义补充。
- 词不确定时，打开“语义补充”；精确查函数和异常时，先用关键词。
- 有题目条件时，打开“显示条件关联”，核对适用、待查和不适用的前提。
- 选好题目工作区后可使用“参考当前卡点”。详细用法见 [遇到卡点怎么查](遇到卡点怎么查.md)。

使用“深度搜索”“直接模式”或“翻译”时才按需加载；完成结果在右侧栏显示。直接模式只发送输入原文，翻译可选目标语言。可以在“设置 → 模型”改为“仅手动启动”，再按“启动”；切换已运行的模型时，保存设置后按“重启模型”。服务状态也可用 `.\启动.cmd -Status` 查看，日志在 `logs/`。

启动入口只为本次调用指定 PowerShell 执行策略，不修改系统或用户设置。
