# 遇到卡点怎么查

1. 打开查询页，先粘贴能核对的线索：函数、报错、题面给出的参数或附件特征。题型不明时，先说看到的现象。
2. 有附件时，在页面上传并查看只读报告，例如文件类型、压缩包成员和可读字符串。根据报告选一两条线索重新查；不要把文件名当作题型。
3. 对相近方法，打开“显示条件关联”，区分已经确认、还要检查和当前不满足的条件。点开原文小节，查看代码适用范围。
4. 在题目工作区记下当前目标、已确认事实和试过的做法。需要查下一步时勾选“参考当前卡点”，对照主结果与补充资料。

例如只看到 ELF 文件时，先查格式和架构；发现输入处理函数后，再查怎样从输入引用定位校验逻辑。输入没有给出的前提先记为待查。

这些操作不需要生成模型。需要解释时按[使用与查询](使用与查询.md)启用。
