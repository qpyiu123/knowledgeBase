# CTF 知识库：离线包使用说明

适用 Windows x64。把整个目录复制到可写位置，保留子目录。无需安装 Python、Node.js 或 Git。模型解释使用显卡驱动提供的 Vulkan；没有可用 Vulkan 时可用 `-CpuOnly`。

## 启动和停止

在包目录打开 PowerShell：

```powershell
.\start.ps1 -NoModel       # 查资料和代码，不加载生成模型
.\start.ps1 -Status        # 查看服务状态
.\start.ps1 -Stop -NoModel  # 关闭查询服务
```

浏览器地址：[http://127.0.0.1:8765/](http://127.0.0.1:8765/)。常用查询直接输入函数名、报错或题面特征。需要更多相近资料时，可勾选语义补充。

若 PowerShell 拦截可信本地脚本，可只为这次启动使用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -NoModel`。不需要修改系统执行策略。

## 选择解释模型

先停止原查询服务。含模型的包可运行 ` .\start.ps1`（双模型包默认 9B，4B 包默认 4B）。两份模型都在时，可临时选择 ` .\start.ps1 -ChatModel qwen35-4b`。停止使用 ` .\start.ps1 -Stop`。

`release-manifest.json` 写明这个包带了哪些模型。搬家时若只想保留 4B，先停服务，在 `config.toml` 的 `[llama_server]` 设置 `model = "qwen35-4b"`，确认 4B 正常启动后，再从**迁移副本**移走 9B 权重。只留 9B 时同理。仅查询时保留 BGE ONNX 和索引；它们不属于生成模型。

单个 9B 权重大于 4 GB。复制到移动硬盘时，使用 NTFS 或 exFAT 等支持大文件的文件系统。

## 题目记录和索引

- 题目记录、已上传附件、反馈分别存到 `work/workspaces`、`work/attachments`、`work/feedback`。新包不带旧记录。
- ` .\backup.ps1` 备份资料、索引和本机记录。用 ` .\backup.ps1 -Restore <备份.zip> -Destination <新空目录>` 恢复。迁移旧题目时，从恢复目录把所需记录复制到包的对应 `work` 子目录，避免覆盖同名记录。
- 资料新增或更改后，先停服务，运行 ` .\start.ps1 -Reindex` 再启动。请保留随包的 BGE ONNX 与分词文件；更换编码器后需要重新生成与它匹配的向量索引，不能混用旧向量缓存。
- ` .\start.ps1 -CheckEnvironment` 查看解释器路径。要换 Python，可加 `-PythonExe <路径>` 或修改 `config.toml` 中的 `[runtime].python`。
