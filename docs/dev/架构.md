# 架构与代码入口

| 部分 | 入口 | 职责 |
| --- | --- | --- |
| Windows 启动 | `启动.cmd`、`start.ps1`、`tools/python-runtime.ps1` | 选择本地 Python、启动和关闭服务、输出状态与日志。 |
| 网页 | `tools/agent/webapp/`、`tools/agent/server.py` | React/Mantine 界面，本地 Python HTTP 服务提供搜索、阅读、附件和题目记录接口。 |
| 搜索 | `tools/kb/fts.py`、`tools/kb/rag.py`、`tools/kb/vectors.py` | 关键词先返回，语义补充按需；SQLite 存储索引。 |
| 条件和题目记录 | `tools/kb/applicability.py`、`tools/agent/workspace.py` | 核对已知条件，保留待查项、假设和尝试；个人记录在 `work/`。 |
| 设置与解释 | `tools/agent/settings.py`、`tools/agent/model_control.py`、`tools/llama_runtime.py` | 个人设置和实际状态分开；首次使用才启动本地实例，支持 Vulkan 和 CPU。 |
| 语言文档 | `tools/kb/language_reference.py`、`tools/kb/fts.py` | 从现有 Markdown 的函数小节写入同一个关键词数据库，精确命中后定位中文说明。 |
| 资料和打包 | `kb/`、`eval/`、`tools/pack_release.py` | 保留资料和评测输入；按需制作可换盘的目录，不把个人资料随包复制。 |

改具体模块前读对应资料：[前端](专题/前端.md)、[图谱](专题/图谱.md)、[检索评测](专题/检索评测.md)、[方法卡协议](专题/方法卡协议.md)、[弱模型资料清洗](专题/弱模型资料清洗.md)。
