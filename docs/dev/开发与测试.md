# 开发与测试

下面命令从项目根目录运行。开发用 `.venv`，实际查询优先使用项目内的独立 Python。

```powershell
.\启动.cmd -CheckEnvironment
.\启动.cmd -NoModel -NoBrowser
.\启动.cmd -Stop -NoModel

# 安装开发依赖（环境缺项时）
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt

# Python 回归与固定问题
.\.venv\Scripts\python.exe -m pytest -p no:cacheprovider
.\.venv\Scripts\python.exe tools\eval_search.py --mode fts
.\runtime\python-portable\python.exe -B -X utf8 tools\eval_real_attachments.py
```

解释器顺序：`-PythonExe` → `KB_PYTHON` → `config.toml` 中的 `[runtime].python` → 自动选择。自动选择先找 `runtime/python-portable/python.exe`，再找 `.venv/Scripts/python.exe`。开发环境不随离线包复制。

只有资料变更需要更新索引。先关查询服务，再运行 `.\启动.cmd -Reindex`；使用当前编码器对应的索引。

改前端时：

```powershell
Set-Location tools/agent/webapp
npm run check
npm test
npm run build
```
