# 路线图

目标：赛中不加载生成模型也能找到语言文档、相关代码、适用条件和下一步检查；模型解释保留为可选功能。

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| 1 | 扩充真题固定集 | 以已下载题为主，目标 15–20 道；记录题源、只读观察、固定查询和预期用途。先补 Misc、Crypto、Reverse，Web、Pwn 暂缓。 |
| 2 | 修正真题暴露的问题 | 先分清缺少资料、条件写错和排序不当；用同一组问题比较原结果和改后结果，并跑原有检索回归。 |
| 3 | 按需准备分发 | 用户确认分发范围后生成所需包。核对换盘、断网查询、说明、资源和许可；解释模型沿用已验证的 Vulkan 路线。 |

进展只写在 [当前进度](当前进度.md)。完成的版本和历史数据见 [版本索引](../records/版本索引.md)。
