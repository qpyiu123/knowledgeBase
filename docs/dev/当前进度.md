## 下一步

1. 优先修正单源码 ZIP、PCAPNG 和 PE 的附件起步提示，让用户能从报告知道该查看哪一部分。
2. 补密码题适用条件与缺少的专题。先用固定题复测完整状态与截断 LCG、RSA 线性组合、曲线参数恢复；再补 NSS 和 CAN 离线取证。保留首轮的 ELF 和非 RSA 模幂对照题。
3. 按实际缺口扩充语言文档，核对比赛机上查询、按需加载和内存占用。
4. 用户确定要分发时，再按 [换盘与打包](../guide/换盘与打包.md) 生成所需规格的离线包。
