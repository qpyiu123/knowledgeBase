- [首批验收](../records/R5.2-真题验收.md)用了两道已下载题。逆向题有起步帮助；密码题缺少围绕已知底数、未知指数和模数结构的资料。

- R6 首轮完成：[统一设置](../records/R6.1-设置与按需启动.md)、[结果侧栏](../records/R6.2-搜索与结果侧栏.md)、[编码器对照](../records/R6.3-编码器对照.md)、[语言文档](../records/R6.4-语言文档首批.md)。默认首次使用时加载，保留仅手动启动；检索用 BGE 量化。首批 47 个函数入口已入索引。

## 下一步

1. 继续使用已下载附件补齐固定真题集，优先 Misc、Crypto、Reverse。
2. 复查 ZIP 未加密提示、ELF 静态起步和非 RSA 模幂这三类缺项。先记录样本，再决定补资料还是调搜索。
3. 按实际缺口扩充语言文档，核对比赛机上查询、按需加载和内存占用。
4. 用户确定要分发时，再按 [换盘与打包](../guide/换盘与打包.md) 生成所需规格的离线包。

长期安排见 [路线图](路线图.md)，具体命令和历史结果查 [版本索引](../records/版本索引.md)。这里只保留最新状态。
