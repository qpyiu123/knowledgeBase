## 下一步

1. 先补普通 ZIP、PCAP/PCAPNG、PE/ELF 的附件起步提示。逆向优先提取位数、导入导出和输入函数，再用旧题和未参与设计的新题检验能否给出下一步。
2. 用固定题复测 LCG、RSA 线性组合和曲线参数恢复；Misc 先修 PNG 编码与 CRC 的说明，补 Linux USB 抓包、宏文件、NSS 和 CAN 的离线操作。保留首轮 ELF 和非 RSA 模幂对照题。
3. 按实际缺口扩充语言文档，核对比赛机上查询、按需加载和内存占用。
4. 用户确定要分发时，再按 [换盘与打包](../guide/换盘与打包.md) 生成所需规格的离线包。
