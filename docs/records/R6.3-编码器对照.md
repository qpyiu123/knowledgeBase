另比较 4 条未标注真题线索，不计入命中率。Qwen 在 ELF 初查中更靠前找到通用逆向工具链，但在未加密 ZIP 查询中把密码卡排在首位；非 RSA 模幂场景两者仍缺合适资料。优先补这类资料。

**项目继续使用 BGE ONNX 量化。** 首位只少两条，前五一致，日常 CPU 查询更快，也不用占用核显给解释留的空间。现用索引已经匹配，不必为了选型重建。项目应用不再启用其他编码后端；旧库 Qwen、原始下载和生成模型保留。上述时间为开发机数据，比赛机另测实际等待时间。

复现工具：tools/compare_encoders.py。指定旧 Qwen GGUF 和项目 work 下的新目录；先用 --device vulkan 构建对照，再用 --device cpu --reuse-indexes <首轮目录> 复测。比较时没有替换现用索引。逐条结果在本机 work/r63-vulkan 和 work/r63-cpu；摘要见 [对照数据](../data/r63-encoder-comparison.json)。
