# PolyRSA：用两组素数线性组合分解模数

本地密码题。使用 [第二轮清单](../../../eval/r65_real_cases.json)中的 `poly-rsa` 原附件。分解、两条额外模幂和原密文均已本机回验；无对应提交页。

源码除了普通 RSA 密文，还给了两条数据：

- `u = (2*p + 3*q)**e1 % n`
- `v = (5*p + 7*q)**e2 % n`

两条底数不同，不能用“同一明文、不同指数”的共模解法。先对素数 `p` 取余，两组底数就分别只剩 `3*q` 和 `7*q`。

把 `u` 再升到 `e2` 次，把 `v` 再升到 `e1` 次。这时两边都含 `q**(e1*e2)`。左边乘 `7**(e1*e2)`，右边乘 `3**(e1*e2)`，相减得到一个被 `p` 整除的数。

```python
from math import gcd
k = e1 * e2
a = pow(u, e2, n) * pow(7, k, n) % n
b = pow(v, e1, n) * pow(3, k, n) % n
p = gcd(a - b, n)
assert 1 < p < n
q = n // p
assert p * q == n
```

找到因子后，先按原式复算两条额外数据。再求 `d = pow(65537, -1, (p-1)*(q-1))`，计算 `pow(c, d, n)`，转成大端字节。最后把明文重新加密，确认余数和附件一致。
