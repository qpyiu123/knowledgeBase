# highlow：素数两端已知，中间有一段被遮住

本地密码题。原附件见 [第二轮清单](../../../eval/r65_real_cases.json)的 `rsa-middle-bits`。本机恢复了素数并按公开密文回验。

源码把 `p` 与左移 400 位的 44 字节明文做异或。因此只有第 400 到第 751 位（从最低位 0 开始）可能变化。先把泄漏值的这 352 位清零，得到 `p0`，然后写成：

```text
p = p0 + 2^400*x，0 <= x < 2^352
```

因为 `p` 整除公开的 `n`，这个式子在未知因子 `p` 下等于零。先用模 `n` 的逆元把 `x` 的系数变成 1：`f(x)=x + p0*inverse(2^400,n)`。这里求的是未知因子下的小根；不是把 `f(x)` 直接当作模整个 `n` 为零。

本机用 Coppersmith 小根方法（把小根问题转成整数向量约简）试算。用 `n^(4-i)*f(x)^i`（`i=0..3`）和 `x^j*f(x)^4`（`j=0..3`）构造 8 行系数，第 `k` 列乘 `(2^352)^k`。用 LLL（整数向量约简算法）找短向量，再除回列缩放，从得到的多项式里取整数根。取整步骤要用精确整数运算，避免大数转浮点后误判。

对每个候选恢复 `p`，检查 `1 < p < n` 且 `n % p == 0`。最后用 `(pxor ^ p) >> 400` 得到明文整数，把它用 65537 次幂重新加密，确认等于原密文。
