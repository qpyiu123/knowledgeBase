# 旧文档审查：先看证据，再决定改哪几篇

2026-11-06，只审查。以下内容是改稿建议，未改 `kb/`、现有文章、资料导入配置或索引。建议先批复 1–4，再决定哪些新题解进入正式库。

| 优先 | 现有文档 | 问题和证据 | 建议改法与验收 |
| --- | --- | --- | --- |
| 1 | [文件修复与损坏识别](../../../kb/misc/file-repair-and-corruption.md#二原理) | 文中把重算 CRC 写成可以修复任意修改；Miniscule 的数据实际是 Zstandard，校验正确也不是合法的标准 PNG 数据。 | 改成“先核对结构与编码，确认字节正确后才重算 CRC”。用该题验两份副本：只改 CRC 的读不出；重编码后独立解码器能读出 800×800。 |
| 2 | [ZIP 压缩包技巧](../../../kb/misc/zip-archive-tricks.md#二原理) | 一处示例把 `09 00` 改成 `00 00`，会一起清掉 bit 3（数据描述符标志）。加密位本身也不能判定伪加密。Nothing to See 用原密码可正常校验。 | 只在副本中按实际条目定位本地头和中央目录；若验证确是伪加密，只清 bit 0，保留其他位。验普通 ZIP、伪加密 ZIP、真正加密 ZIP 三种。 |
| 3 | [音频隐写](../../../kb/misc/audio-steganography.md#dtmf--摩斯--调制) | 摩斯示例直接对每个采样取绝对值，不会给无符号 8 位 WAV 减 128，也会把载波过零当成停顿。DTMF 是两音同时存在，不是两个单音交替。 | 先按位深居中，再按短窗口算能量，从音长、停顿的分布分段；把摩斯、双音和双频交替分开。用 Beep Boop Robot 回验 51 字符与 9 个词。 |
| 4 | [线性同余随机数预测](../../../kb/crypto/lcg-predict.md#二原理) | 截断示例称商通常只有 0 或 1，也把未知数的乘积写成“线性化”。例：`m=11,a=7,b=1,x=10`，除法商是 6。Lunar LCG 的低位是密钥流，泄漏数据是完整状态。 | 先分完整状态、低位、高位三类；低位只有在原模数是相应的 2 的幂的倍数时才可直接降模。已知模数用完整状态公式；未知参数与状态相乘时明确是非线性，并用多项回验。 |
| 5 | [虚拟机保护](../../../kb/reverse/vm-protection.md#三checksec-判读与利用思路) | 大分支表和 `VirtualProtect` 被写成直接结论。上一轮只确认 jocker 有该导入；公开题解的进一步证据是随后写入并调用了同一代码范围。 | 拆开“找到分派”“核对代码写入”两张短卡。前者检查取指、指令位置与分派；后者核对参数、写入目标和后续调用。加一个正常调用系统 API、未修改代码的反例。 |
| 6 | [浏览器取证](../../../kb/forensics/browser-artifacts.md#二原理) | 主体按 Chromium 的文件结构讲。FireFox Forensics 的实际输入是 `key4.db` 与 `logins.json`，两者的密钥与登录字段算法也不同。 | 增加 Firefox 的独立入口：文件配对、主密码校验、按密钥编号关联。保留 Chromium 原段，不混写字段。用公开赛题附件核对。 |
| 7 | [流量分析](../../../kb/forensics/pcap-basics.md#二原理) 与 [USB 流量](../../../kb/_imported/misc/USB流量分析.md) | USB Hacker 是链路类型 220，按 Windows USBPcap 头解析得到 0 条；按 Linux 格式得到 252 条。两轮附件报告还把经典 PCAP 和 PCAPNG 报作未知。 | 先在资料中加“容器 → 接口链路类型 → 具体头格式”三步，用 Linux 和 Windows 各一份离线包验；附件识别与检索分类另行修改。 |
| 8 | [PDF 与 Office 文档](../../../kb/misc/pdf-and-doc.md#二原理) | 宏提取示例集中在旧式 OLE 文档。Macro Magic 中是 `.xlsm` 外层 ZIP，内有 `xl/vbaProject.bin`；只在取证分类里查时相关 Office 资料也没进前五。 | 补 `.xlsm`/ `.docm` 的内层宏分支，只读提取，不开启宏。后续再比较跨分类入口，不先改排序。 |

规范核对：[PNG](https://www.w3.org/TR/png/)、[ZIP 格式说明](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)、[Linux usbmon](https://cdn.kernel.org/doc/html/latest/usb/usbmon.html)、[Firefox 文件配对工具说明](https://github.com/lclevy/firepwd)。
