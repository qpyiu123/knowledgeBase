# R6.5：控制窗口与侧栏

日期：2026-11-06。

## 这版变化

- 双击 `启动.cmd` 后保留命令窗口。关浏览器不会停止查询；关闭命令窗口或按 Enter，停止本次启动的查询服务和由它启动的解释服务。已有服务和浏览器不受影响。
- 文章和任务结果各自保留本次使用的宽度。拖动左边缘可调整，也可用 Tab 选中边缘后按左右方向键。文章侧栏较窄时收起目录，给正文留空间。
- 去掉左上角字标，浅色和深色都换成蓝灰配色。查询方式、资料和模型默认按需加载规则保持不变。

## 实现要点

`启动.cmd` 无参数时传入 `-Console`，其他命令行参数沿用原用法。[Windows Job](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects) 负责随控制窗口退出而结束本次后台进程；先加入等待中的启动进程，再让它运行 Python，便携和虚拟环境解释器都走同一套控制。只接管新开的服务，端口已有监听时提示先返回原窗口或停止原服务。

## 测试

- Python 495 项、前端 55 项通过；前端类型检查与生产构建通过。
- Windows 实测：不预加载模型；关浏览器后服务继续运行，按 Enter 后查询服务退出。以强制结束控制进程模拟直接关闭窗口，查询服务与已启动的 4B 模型进程均退出，端口释放。
- Edge 实测：浅色和深色主题、文章和深度搜索侧栏鼠标拖动、键盘调整、重开宽度与窄屏限制。侧栏操作使用固定测试结果，另外读取了本地文章验证文档接口。
