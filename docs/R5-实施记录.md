## R5.1 本批范围

- 用当前项目和已有资源生成一个可复制的 Windows x64 目录。默认保留 9B 和 4B、启动默认选 9B；可只带 9B、只带 4B 或不带生成模型。选择在打包时生效，源文件不删除。
- 打包现有网页、知识库、已匹配的索引与 BGE ONNX、独立 Python 和所选解释模型。排除 Git、个人记录、附件上传目录、日志、下载半成品和开发环境；附文件、来源和许可清单。
- 按同一启动入口检查带中文空格的新路径及替代盘符。开发机做本地查询、代码阅读、语义补充、保存、备份恢复和实际 Vulkan 解释，记录测试的网络隔离方式。
- 比赛机 8845HS / 24 GB 的物理断网验收作为 R5.2，使用同一目录和验收表，不把开发机结果记成比赛机结果。

只准备本地迁移目录，不上传，不改系统网络，不清理原模型。
