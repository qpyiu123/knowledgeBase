# R5.2 本机真题验收

2026-11-05。用户确认移动包在本机验收即可，笔电已验证过的 Vulkan 推理方案不再重测。R5.1 的迁移和模型运行结果仍见 [R5 实施记录](R5-实施记录.md)。

## 本批范围

- 真题集目标 15–20 道，优先 2018–2024 年大型比赛的代表性 Misc、Crypto、Reverse 题。Web、Pwn 留待用户补齐离线集。本批只用已经下载的附件，不补下载。
- 原件按方向和题目归到 `work/r52/真题测试集/`，不在下载目录里分析。相同附件保留副本，只计一题。`eval/r52_real_cases.json` 记录来源、文件指纹、实际观察和固定查询。附件本身不入 Git，也不进离线发布包。
- 每题先走本机上传和只读侦察，再用报告直接能看到的线索查一次，用已确认的补充线索再查一次。对同一查询比较关键词和语义混合前五。不把题名、题解、已知答案或方法名写进输入。不运行附件、不启动靶机、不解题和提交。
- 逐条检查：资料能否打开，是否指出当前现象对应的下一步检查，有无漏掉决定方法的前提。只匹配到容器或程序格式，记作起步资料；只提到相似名词，记作未找到。当前样本少，先记录问题，不据此改排序。

## 首批样本和结果

内嵌浏览器在 DASCTF 的 BUUCTF 练习场核对了题名、比赛、附件大小和 MD5。下载目录中三份文件均已移动，原始内容不变；逆向两份的 SHA-256 相同，计作一题。Misc 只看到了候选题，没有已下载附件，目录留空。

| 真题 | 上传报告与补充观察 | 前五结果是否有帮助 |
| --- | --- | --- |
| 2020 网鼎杯青龙组 · you_raise_me_up | ZIP 列出一个未加密的 Python 文件。评测者只读成员文本，确认模数是 2 的幂、底数为奇数、未知量是指数。 | **未找到合适资料。** 报告查询把未加密包排到密码攻击卡附近；补充条件后，关键词与混合结果都偏到小指数 RSA 等方向，没有围绕已知底数、未知指数和这个模数解释要先检查什么。 |
| 2020 UTCTF · basic-re | 无后缀的文件识别为 Linux ELF。报告未展示架构；只读文件头确认 x86-64，字节字符串中有 `scanf`、`printf`、`main`。 | **有起步帮助。** 报告查询的混合前五第 3 条“逆向工具链与快捷键速查”给出 `readelf -hS` 与字符串检查。补充线索后，前五有汇编速查和校验相关资料，仍未把“从输入引用定位校验”放到好找的位置。 |

Windows 开发机、独立 Python 3.13.17、现有 1917 篇索引。通过本机 HTTP 完成 2 次上传、8 次搜索；两题返回的 17 / 13 篇不同资料分别通过阅读接口打开。报告阶段的查询不筛方向，补充线索阶段按题目方向筛；只在同一条查询内比较关键词与混合结果。两种搜索分别耗时 46.1–145.6 ms / 83.5–226.0 ms（接口报告值，含本轮首查）。没有调用生成模型。

Python 全回归 475 项通过（64.61 秒），新增脚本的 Ruff 检查和格式检查通过。本批未改产品代码或前端。
