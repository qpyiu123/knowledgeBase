## 为什么没有整目录删除旧便携版

逐文件比较发现，解压目录有 109 个文件在 ZIP 中不存在或内容不同，合计 63,106,467 字节。全部保留，其中包括：

- 内容与 ZIP 不同的 state.sqlite3，60,641,280 字节。
- 大小不同的 preferences.json。
- 新产生的日志和缓存。

尤其是状态库：文件大小与 ZIP 内版本相同，但 SHA256 不同。只比较文件名或大小会误删这份不同的数据。

## 删除判据与执行范围

1. 逐文件读取解压目录和 ZIP 对应成员，分别计算 SHA256；文件大小和 SHA256 都相同才进入删除清单。
2. ZIP 缺少的文件、大小不同的文件、内容不同的文件全部保留。
3. 删除前再次核对 ZIP 大小、修改时间、目标文件哈希及绝对路径边界；遇到链接或内容变化立即停止。
4. 经权限确认后，只删除旧库 release/CTF知识库-3.1.0-Windows-x64 内清单指定的重复文件。没有递归删除整个发布目录。
