## 使用

```powershell
.\start.ps1 -CheckEnvironment
.\start.ps1 -NoModel
.\start.ps1 -NoModel -PythonExe '.venv/Scripts/python.exe'
$env:KB_PYTHON = 'D:/my-python/python.exe'
```

config.toml 的 `[runtime].python = "auto"` 为默认值。选择顺序为参数、KB_PYTHON、配置、自动；相对路径按项目目录解析。显式路径出错会直接报错。

便携运行文件在 `runtime/python-portable`，版本清单见 `docs/data/r13-runtime.json`。运行目录、DLL、Python 包和许可保留在本地，不提交 Git。开发环境 .venv 仍为 Python 3.12。

## 修复的问题

- 旧 pip 按 GBK 读中文依赖文件：准备工具按本次命令启用 UTF-8。
- 嵌入模式会忽略 PYTHONIOENCODING：JSON、验收摘要和备份输出显式使用 UTF-8，PowerShell 探测时临时按 UTF-8 读取，随后恢复原编码。
- 旧健康检查即使只查询也探测模型：`-NoModel` 现会跳过模型请求，并对模型解释返回明确的关闭提示。
- Windows 后台进程会继承启动器管道：验收用独立日志文件；仅核对并停止本次创建的测试 PID。旧测试过程的自建进程已清理。
